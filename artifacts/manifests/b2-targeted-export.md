# B2 таргетированный экспорт рёберной окрестности стора — рукопожатие

> Контент в репу НЕ входит (гигиена данных, data-contract §6): здесь
> счётчики и фингерпринты. Корпус живёт локально в
> `data/pretrain/b2-edges-20261002/` (gitignored); валидность = пересчёт
> фингерпринтов из локальных файлов совпал с этой записью. Пакет —
> источник датасета v3 (граф-признаки): пул + серебряные рёбра +
> пары-кандидаты near-dup.

- **Дата экспорта:** 2026-10-02 · ветка `feat/b2-targeted-export`
  (коммит `8d45033`)
- **Источник:** стор движка vesmaro (`mnemos.db` + `vectors.db`), доступ
  строго read-only (`file:…?mode=ro` + `PRAGMA query_only`); sha256 обеих
  баз до и после экспорта совпали байт-в-байт — стор живой (MCP), не
  тронут
- **Режим:** таргетированный (`export_targeted_corpus` +
  `scripts/b2_targeted_export.py`) — сиды = все 386 конечных узлов
  `memory_edges` (сгенерированы из стора read-only, файл
  `data/ids/edge-node-ids-20261002.txt`), 1-hop-расширение замкнутое
  (386 → 386): вся рёберная окрестность графа уже покрывается
  конечными узлами
- **Гигиена (порядок препрега, заморожен — тот же код, что A2):**
  SQL-отбор по candidate-id → сканер секретов движка + danger-детекторы +
  `no-federate` + `quarantine` ДО любого вывода → минимальный состав
  (title, body, tags, language, record_type, created_at, content_hash,
  vector). Исключения — только счётчики по причинам.
- **Сканер:** провенанс `engine` — детекторы движка исполнены из
  read-only worktree (`wt/a2-engine-readonly`); fallback не использовался

## Передача создателю датасета v3

- Вход: `records.jsonl` (пул, формат A2) + `silver_edges.jsonl`
  (граф-позитивы с kind+provenance) + `near_dup_candidates.jsonl`
  (базы corruption/hard-negative того же назначения, что в A2-потоке);
  валидация — пересчёт трёх фингерпринтов и `edge_sha256` из join
- Покрытие графа: 97.8 % рёбер (613/627) полностью внутри пула; полная
  рёберная топология восстановима из `silver_edges.jsonl` + join
- Ограничение, о котором знать: 13 узлов `session_context` сознательно
  вне пула (замороженный цикл record_type) — их 14 рёбер в экспорте нет;
  если датасету v3 понадобятся они, это отдельное решение по контракту,
  не правка экспортёра

## Статус

Пакет собран и само-согласован (три фингерпринта воспроизведены вторым
прогоном, все 613 `edge_sha256` проверены из join, стор байт-в-байт не
тронут). Сьют 311 зелёный. Потребитель — срез датасета v3 (граф-признаки
is-duplicate v2, ADR 0002).
