# Стадия 1 — прогон обучения (рукопожатие, не A5-решение)

> Контент (модели, векторы, пары) в репу не входит; здесь — идентификаторы
> и вердикты. Это ПРЕДВАРИТЕЛЬНЫЙ прогон конвейера на синтетике: финальная
> селекция кандидата и артефакт для движка — только после стадии 2 на
> владельческих метках (A5 по препрегу v2).

- **Дата:** 2026-09-30 (ночь) · CPU, 14 ядер (taskset 2–15), OMP_NUM_THREADS=14
- **Обучающий корпус:** синтетика 1350 пар, производный (similarity + векторы)
  `data/synth/pairs.sim.jsonl`, фингерпринт `f6171b50c69f762e…` (базис —
  корпус `621cb23f`, докомпьют NanoProvider engine-venv, embed text
  title+body+tags обрез 4096 по препрегу, ноль сети)
- **Претрейн-корпус N:** corruption-пары из стор-пула 794 → 1588 пар
  (794 weak-positive + 794 hard-negative), фингерпринт `a6a4835f…`,
  seed 0, детерминированно

## Вердикты (CV на синтетике, stratified 5-fold × 20 сидов)

| Кандидат | Конфиг | BA | Brier |
|---|---|---|---|
| D (лучший) | d-l15-lr010 | **0.9774 ± 0.0023** | **0.0165 ± 0.0013** |
| N + претрейн | n-h128-64-pt | 0.9690 ± 0.0025 | 0.0176 ± 0.0007 |
| N с нуля | n-h64-32 | 0.9425 ± 0.0033 | 0.0314 ± 0.0009 |

- **Селекция:** победил D (margin −3.41 std — N не проходит барьер «>1 std
  по обеим метрикам» на этом материале; правило ADR V1 «при сомнении — D»).
  НЕ предрешает финал: реальные страты вокруг порога 0.92 — другая задача.
- **Абляция претрейна (ADR V1):** подтверждена — лучший N с претрейном
  +2.65 п.п. BA и −0.014 Brier против лучшего scratch-конфига.
