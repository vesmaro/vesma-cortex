## Определение поверхности g4-spec-v1 (одно чтение на гейт-цикл)

1. **Источник**: живой стор, read-only зонд рецепта переписи §5.1 на
   момент вырезания; снапшот фиксируется fp.
2. **Строки**: пары (record, candidate), у которых evidence-флаг =
   (`edge_ab=1` ∨ `common_neighbors≥1`), обе стороны разрешены,
   cos ≥ 0.97 (замороженный эмбеддер, формула сборщика), серебро §A →
   NOT dup (спорное → NOT dup, §8.3; вся зона минта NOT-dup по переписи).
3. **Исключения (ассерты вырезания)**: pair-level дизъюнктность против
   train v4.5 (fp `3bf7ed53…`, обе ориентации), против записей страты A,
   против всех исторических holdout-поверхностей (v4.1/v4.2/v4.3/v4.4)
   и против holdout v4.5 (seal `9eae5ec1…`).
4. **Без сабсэмплинга**: поверхность = вся отобранная популяция банда.
   Если квалифицированных пар < 30 — СТОП и эскалация TL (определение
   не ужимать).
5. **Заморозка**: evidence-колонки фиксируются при вырезании + ассерт
   согласования со свежим sidecar'ом (дисциплина A2.5.3); одна
   ориентация на пару, seed фиксирован.
6. **Seal**: fp по [(pair_id, pair_sha256)] канонической функцией
   сборщика; одно чтение гейт-раннером; после запечатывания не меняется.

Порог spec ≥ 0.90 (A2.7) не меняется. Recall-нога g4′ (holdout страта A)
не затронута. Отчёт о вырезании — в run-log и отчёте волны владельцу.
