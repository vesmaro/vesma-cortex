# Прег merge-arbiter — АДДЕНДУМ 2: ратификация интерпретации δ_acc / floor_seed (2026-10-29, ДО single-shot)

- **Статус:** РАТИФИЦИРОВАН MLC 29.10 (триггер 2 — интерпретация допуска;
  письменный раунд, три позиции единогласны). Исполнено до gate_start
  (аддендум ДО прогона; перемер после single-shot запрещён машиной —
  InstrumentAbort, проверено исполнением).
- **Спор:** §5 задаёт δ_acc := max(2·floor_seed; 0.10), §4 определяет
  floor_seed как Δacc(модель−базлайн) между розыгрышами. Таблица
  `floor_seed_max_abs_delta` манифеста сборки — постратный шум БАЗЛАЙНОВ
  (модельной ноги при сборке не было, §6.1 — проекция); максимум 0.25 =
  CH-3/chain/keep-oldest (3 флипа на 12 кластерах). Буквальная подстановка
  дала бы δ_acc = 0.50 — гарантированный ложный DECLINE (потолок дельты
  ≈ 0.48).

## 1. Ратифицированная интерпретация

**floor_seed для δ_acc меряется на гранулярности гейтующей величины
(CH-3-агрегат: 22 k2 + 3 chain = 25 кластеров) на train-стороне ДО пуска;
постратная таблица манифеста — characterization-артефакт сборки, в формулу
не подставляется.** Минимум 0.10 остаётся ратифицированным конвертом
модельной стороны (training-seed шум не измеряется — модель тренируется
один раз).

## 2. Ратифицированная процедура замера (исполнена, коммит f2e2ef3)

1. 10 розыгрышей, seeds {43..52} пинены списком в run-log; розыгрыш =
   CH-3-агрегат композиции гейтового плеча из свежего синтетического
   материала (замороженный `gen_family`, тот же кодовый путь, каунт-ассерт
   25 на розыгрыш).
2. delta_d = acc_choice(замороженная модель merge_arbiter_v1.json sha
   `85fa9276…`, агрегат d) − max(keep-oldest, longest-body, first на
   агрегате d); модель не переобучается.
3. floor_seed_aggregate := max попарных |delta_d − delta_e| (семантика
   `max_abs_delta` манифеста).
4. δ_acc := max(2·floor_seed_aggregate; 0.10); при floor ≤ 0.05 —
   автоматически 0.10. Фиксация в run-log frozen_inputs ДО gate_start.
5. Дизъюнктность fail-closed: ids розыгрышей ∩ train.jsonl = 0;
   ∩ id-манифест MA-holdout-choice = 0 (чтение id-уровня, контент не
   читался, факт чтения в run-log); сценарии розыгрышей ∩ train-сценарии
   CH-3/CH-4 = 0.

## 3. Результат замера

floor_seed_aggregate = **0.12** (пара seeds 43/51: delta 0.48 vs 0.36;
модель 250/250 на всём свежем материале — вариативность целиком от жребия
композиции max-базлайна 0.52–0.64) → **δ_acc = max(2·0.12; 0.10) = 0.24**.
Гейт g_acc проходим при реалистичных числах; prior-риск букво-чтения 0.50
устранён. Числа: `datasets/merge-arbiter/merge-v1-thresholds.frozen.json`
секция `delta_acc_measure` (sha df51698f…); гейт-раннер читает δ_acc
только из ратифицированной секции (отсутствие = InstrumentAbort).

## 4. Отвергнутые альтернативы

- (b) плоский 0.10 без замера: ассерт вместо измерения против ML-STD-0001;
  арифметика манифеста (0.25 на страте из 12 ≈ 0.10–0.12 на агрегате из
  25) говорит, что 0.10 — вероятный недомер В НЕБЕЗОПАСНУЮ сторону.
- (c) буква 0.50: шум страты из 12 кластеров приложен к статистике из 25;
  анти-гейт — красит идеальную модель.
