# Prereg — датасет состава окна (L3 curator-линия) v0

- **Дата:** 2026-10-31 · **Статус:** DRAFT — ратифицирует MLC (числа —
  ориентиры раунда 8, финализирует ратификация v1) · **Компаньон:**
  [ADR 0007](../decisions/0007-window-telemetry-two-planes.md)

## 1. Пример датасета

Пример = (assembly_id, query_hint_sha256, блок-без-текста, метки).
Контент догружается по `memory_id` из живой базы в момент тренировки
(локально, законно); лог текстов не хранит. Сплит — по session, не по
блоку (утечка №1); дедуп по `dup_group` ДО сплита; стратификация по
project/agent; тест замораживается одним открытием.

## 2. Иерархия меток «использован» (отдельные колонки, компоновка постфактум)

- **L+3 цитата** (сильная): ответ модели пересёкся с блоком (n-gram 8 +
  эмбед-порог); ставится только если харнес отдаёт ответ в hook, иначе
  честно «не собираем» в датасет-карте.
- **L+2 действие** (средняя, с первого дня): следующий tool-call ссылается
  на сущность из блока.
- **L+1 выживание** (слабая, бесплатная, дефолтная): блок пережил ≥3
  последующих пересборок без CCR-сжатия.
- **L0 не использован**: ни один сигнал за T = 3 сборки или 30 минут; скоуп мёртвости — всегда окно T, никогда одна сборка.
- `re_requested` (коррекционный канал мёртвости): та же сущность/слот перезапрошена после выхода блока из окна в пределах T — засчитывается в коррекцию доли мёртвых (§3) и как отдельная колонка датасета; самостоятельным основанием эвикционных решений L2 не является.
- Анти-прокси: `wrong_tool_flag` из usage_reports.
- Слепая зона всех прокси (фиксируется): контрфактическое отсутствие
  (эвицированный блок не генерирует сигналов по построению — виден только
  через повторный запрос) и синергия блоков. «Мёртвость» — вероятностная
  оценка, не приговор; эвикция по признаку «длинный и не процитирован»
  в L2-правилах ЗАПРЕЩЕНА (убивает кондиционирующий контекст).

## 3. Полы и триггер L3 (все три условия одновременно)

1. Объём+полнота: ≥2000 assemble-циклов с full-join за ≥30 дней при
   usage-coverage ≥80%.
2. Качество прокси: F1 ≥ 0.8 прокси-меток против expert-выборки на ≥200
   блоках (метки expert-выборки ставит комитет-серебро — choice-арбитр
   v2, ADOPT 30.10; золотая калибровка владельца ≤50 блоков — §4);
   ниже — метки годны только для L2, L3 заблокирован.
3. Сигнал цели: доля «мёртвых» блоков ≥15% (иначе эвикции нет мишени;
   это же — главный базлайн L2).
Проба сигнала ДО обучения (урок fusion): rules-прогноз на L+1; AUC <0.60
→ L3 не открывается. Полы датасета ДО линии — урок K7.

## 4. Гейты L2 (rules-curator v0) — advisory-first

- Знаковая разметка исходов (протокол комитета-серебра: постоянные
  метчики — choice-арбитр v2, новый компонент не создаётся; выборка ≤50
  блоков, владелец — только золотая калибровка ~15 мин/цикл, метки never
  в train): tie ≥60% и loss ≤10%.
- Cache-ось: стабильность кэша ≥0.95 базлайна (cost = c_fresh·fresh +
  c_cached·cached — двойная бухгалтерия обязательна: эвикция, роняющая
  кэш, может быть нетто-отрицательна при меньшем окне).
- Critical-loss rate <5% (эвицированные-но-процитированные блоки с
  деградацией ответа).
- Лестница агрессивности: conservative → standard → aggressive, полный
  no-harm прогон на каждой ступени, перескоки запрещены.

## 4.1 Стоячие базлайны еженедельного фриза

Каждый фриз публикует: долю дубликатов в W2 recall-блоках до/после арбитра W1–W3 (до волны — pairwise-похожесть внутри assembled-блоков); суммарные токены окна по классам W0–W4 (перцентили p50/p90 на сборку).

## 5. Retention и приватность

Сырые события сайдкара — TTL 90 дней (движковый); фриз еженедельный
(нефризенное теряется); суточные агрегаты — бессрочно; датасет L3
версионируется отдельно (дата-карта + ревизия, QA-гейты на каждом бампе).
Текстов памяти в логе нет (memory_id + sha256(norm(content))); secret-scan
на границе фриза; экспорт наружу — только агрегаты после secret-scan.

## 6. Приёмка экспортёра (первый артефакт)

`scripts/export_window_dataset.py`: read-only mode=ro над сайдкаром;
join-полнота (usage-coverage в отчёте); derived-поля — по ADR 0007 §2
(ccr_expanded, redactions>0, dup_group, age_days, in_cache_prefix,
content_type = класс W0–W4) — считаются экспортёром; манифест+фингерпринты фриза;
secret-scan; недельный каденс.
