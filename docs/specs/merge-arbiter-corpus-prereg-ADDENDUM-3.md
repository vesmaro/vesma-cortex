## 1. Новая негативная страта `theme-near` (label = abstain by construction)

- **Семантика:** класс 8 таксономии §A (тема-рядом: разное содержание при
  общей теме / разные факт-слоты при поверхностном сходстве / разные
  языки). НЕ CH-4 (предикат razor не выполнен — тела различимы существенно),
  НЕ CH-2 (метаданные совпадают). Замыкающее правило §2 «класс не
  определён → ABSTAIN» уже покрывает семантику; аддендум делает класс
  явным для ассертов. `stratum="theme-near"`, `substratum ∈ {template-twin,
  near-topic, cross-lang-sibling}`, declaration несёт sibling-justification
  (валидатор непустой обосновки переиспользуется из v4.3 — A-labels
  расширяется).
- **Квоты (пере-ратифицированная строка §3.2):** блок негативов 200
  кластеров СВЕРХ нетронутых 600 (итог 800; CH-3 240 не разбавляется):
  cross-lang-sibling 80 (40 спек × 2 ориентации), template-twin 60,
  near-topic 60. Анти-прокси-граница: кросс-язык ≤ 1/2 негативной массы
  (иначе модель выучит «разный язык → abstain» вместо «разное содержание
  → abstain»).
- **Конструкция:** обе ориентации сериализации на каждой паре (A-symmetry
  РАСШИРЯЕТСЯ на негативные страты); created_at/позиция/форматирование
  рандомизированы независимо от метки (A-created-indep, A-order-indep
  переносятся); генераторы заморожены (0 правок, A-frozen); переносится
  A-regime; preflight на фикстурной ячейке нового класса до emission (П3).

## 3. Порядок пере-заморозки (все шаги до gate_start; ни один не читает MA-holdout-choice)

1. Генерация страты (свежие seeds ≠ сид-семейство 42, список пинится в
   манифесте ДО генерации) + ассерты §2 → крас = стоп до обучения.
2. Retrain (seed/конфиг/чекпоинты/JSON+sqlite) → re-CV τ_hi/τ_m по §2.2
   (фолды попарно-дизъюнктны, train-only) → новый frozen-артефакт
   (byte_tripwire на новый sha).
3. **Пере-выводятся ВСЕ состав-зависимые пороги** (ловушка: заморозка с
   старыми флорами = порог-фиттинг задним числом): floor_q (≥10 розыгрышей
   → новый q для g_abstain_sens), floor_seed (ратифицированная процедура
   ADDENDUM-2, 10 розыгрышей, НОВЫЙ sha модели → новый δ_acc), floor_inv,
   floor_perm.
4. Санити §6.1 — 7/7 через производственный контур §5.1 с новой моделью
   (пробы 3/4 — сторож CH-3-качества).
5. QA-диагностика noharm: ожидание 0/171 + 0/27; крас = разбор рецепта
   (поверхность не трогается).
6. Пре-launch чеклист на новом sha: пре-чек листа, QA-лестница ADDENDUM-1
   §4 (консенсус-метки модель-независимы — скоринг не повторяется),
   committee-scored-v1.json ∉ входов (машинный ассерт пролога).
7. Single-shot по ML-STD-0003, полный пролог, g_spot меряет НОВУЮ модель
   против тех же замороженных консенсус-меток.
