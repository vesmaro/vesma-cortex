## A2.1 Формальное серебряное правило cross-lang дубликата (расширение §A)

Пара A,B с lang(A) ≠ lang(B) — **duplicate** ⇔ выполнены ВСЕ предикаты:

1. **Двустороннее сохранение слотов**: существует биекция слотов
   S = {(имя, v_A, v_B)} по §8-классам ключевых фактов policy v1.1
   (числа/даты/имена/версии/суммы), каждый слот A имеет равный слот в B и
   наоборот (равенство на канонической форме значения).
2. **cos-банд**: cos ∈ [0.55, 0.86] (замороженный эмбеддер, формула
   сборщика).
3. **Конверт-инварианты**: tag_jaccard = 1.0; type_match = 1.0;
   tag_count_delta = 0.
4. Спорное → NOT dup (§8.3).

Операционализация — **генераторная бухгалтерия слотов**: пара строится из
таблицы слотов, обе стороны порождаются из ОДНИХ значений, слот-карта
пишется в манифест сборки (дайджест, не сырой текст). Два подсемейства:
**T (verbatim)** — факт-токены копируются без перевода, предикат 1
проверяется containment-ассертом в обе стороны; **V (free)** — слоты
вербализуются, предикат 1 проверяется равенством слот-карты (char-ликаж
логируется монитором, НЕ ассертится). LLM-разметчик допустим только как
офлайн-черновик шаблонов, замороженный до сборки; метка = функция
построения.

## A2.2 Класс-контракт генератора translated-dup (перегенерация/добор)

Гарантии: дубликат и sibling порождаются из ОДНОГО шаблона-скаффолда
(alignment §D: класс → генератор-параметры → и трейн-инстансы, и пробы).

Ассерты сборки (иначе сборка НЕ запечатывается):

- **dup (T)**: containment каждого слота в обе стороны ≥ 1 вхождения;
  ch3_containment ≥ 0.01; cos ∈ [0.55, 0.86]; body_len_delta ≤ 60.
- **dup (V)**: равенство слот-карты; cos ∈ [0.55, 0.86]; body_len_delta
  ≤ 130; ликаж-монитор в run-log.
- **sibling (v4.2-рецепт, при доборе)**: НИ одного общего слот-токена;
  cos-банд попарно согласован с dup-бандом той же ячейки (±0.005);
  tag_jaccard = 1.0; lang_match = 0.
- **Квота/паритет**: в каждом cos-бине [0.55,0.65) / [0.65,0.75) /
  [0.75,0.86] — n_dup ≥ n_sibling замороженного блока 144 в этом бине
  (паритет ≥ 1.0), K ≥ 30, непрерывность cos ≤ 0.005 (§D-б).
- **Скаффолд-антиколлапс**: ≥ 20 скаффолдов, ≤ 5 % строк класса на
  скаффолд.

## A2.3 Добор class-7 same-language и N-near tag-clone

- **class-7 same-language**: v4.2-совместимая однофактовая правка
  (короткое тело), паритет ≥ 1.0 по ячейкам ch5_jaccard
  [0.80,0.85) / [0.85,0.90) / [0.90,0.95) при cos ≥ 0.985, lang_match = 1,
  K ≥ 30 на ячейку. Аудит-ассерт: каждая новая class-7 строка объявляет
  lang-группу (молчаливый перекос «добавка ушла в lm=0» невозможен).
- **N-near tag-clone**: same-language, tag_jaccard = 1.0, cos ∈ [0.78,0.92]
  бандами ±0.005, body_len_delta ≤ 60, K ≥ 30 на банд, паритет ≥ 1.0 против
  суммарной позитивной массы той же ячейки.

Целевые метрики добора (обоснование — NA §4): N-fact-edit spec ≥ 0.95,
N-near spec ≥ 0.90 — иначе коридор g3 ≥ 0.9449 арифметически недостижим.

## A2.4 Страта A — реальные пере-сохранения (новый позитивный класс)

- Источник: зонд живого стора (read-only, рецепт переписи §5.1) на момент
  сборки: real-real silver-dup пары (тело+заголовок норм-равны, теги/тип/
  язык равны, created_at различается ≤ минуты — whitelist §8.1, cos ≡ 1.0).
  Снапшот при сборке фиксируется fp; рост популяции между снапшотом
  переписи (68) и снапшотом сборки disclosed в манифесте.
- Структура: кластеры пере-сохранений (62×2 + 2×3 на переписи).
  **Кластер-целостность**: кластер НЕ рвётся между train и holdout.
- Квоты: holdout v4.5 получает 2–3 ПОЛНЫХ кластера; train-масса страты
  ≥ 30 пар (K). Ассерт непрерывности §D-б к страте A НЕ применяется
  (одноточечный банд cos ≡ 1.0 — задокументированное исключение).
- Дизъюнктность pair-level против всех исторических поверхностей — ассерт
  сборки. Страта A содержит нулевой граф-вектор по построению (записи
  движком не связаны) — g4′ на ней меряет recall полной модели, НЕ абляцию.

## A2.5 Sealed holdout v4.5

Свежий sealed 10 % из НОВОГО материала v4.5 (v4.4-holdout сожжён и не
реанимируется), seed фиксирован, замок seal = fp у TL:

1. Стратификация выборки: **label × evidence-флаг × страта** (evidence —
   свойство строки, не страты).
2. mint-top распадается на **mint-top-evidence / mint-top-zero** —
   отдельные квоты (урок v4.4: 6 из 7 mint-top строк holdout были
   нулевыми — «эвиденс-страта» молча разбавилась).
3. ОДНО чтение термина на весь гейт-цикл: замороженные колонки при сборке
   + ассерт согласования со свежим sidecar'ом на гейте; строки с
   неразрешившимися сторонами → карантин счётчиком, не в молчаливый минус.
4. Дизъюнктность pair-level + срез side-оверлап-флагов при вырезании.
5. `cos_to_common_max` фиксируется в экспорте (в v4.4 вырождался в 0.0 для
   половины граф-блока).
6. Representation-ассерт §D расширен на evidence-материал (K=30 +
   непрерывность внутри dup-с-эвиденсом материала, где применимо).

## A2.6 Гейт g1b — флора невиденных скаффолдов (новый)

Отдельный гейт (НЕ 10-й зонд g1: замороженные константы sanity v2 и
сравнимость 9/9 между раундами сохраняются). Класс риска иной: g1 ловит
инверсию границы, g1b — генерализацию на невиденном скаффолде. Пробы тем
же генератором рецепта (alignment §D); скаффолд-дизъюнктность с
трейн-инъекцией — ассерт сборки; считается на обеих моделях ДО чтения
holdout; **красный g1b = holdout не читается** (семантика аборта как у g1).

| Проба g1b (невиденный скаффолд) | Порог |
|---|---|
| парафраз-dup | P(dup) ≥ 0.95 |
| факт-правка | P(dup) < 0.5 |
| cross-lang dup (рецепт A2.2) | P(dup) ≥ 0.5 |
| cross-lang sibling | P(dup) < 0.5 |

## A2.7 Гейт g4′ — реальные пере-сохранения + специфичность (замена g4)

- **g4′ = (recall полной модели на holdout-страте A = 1.0) ∧ (spec на
  evidence hard-негативах банд рёберных cos ≥ 0.97 ≥ 0.90)**.
- Обоснование формы: страта A — cos ≡ 1.0, самые лёгкие позитивы;
  промах на удержанном пере-сохранении = красный флаг. Пороги PROPOSED —
  владелец утверждает или правит (поз. 2 пакета).
- Абляция в g4′ НЕ входит: страта A граф-мёртва по построению; вопрос
  аттрибуции графа вынесен в характеризацию A2.8.
- Верdict ревизии = конъюнкция g1, g1b, g2, g3, g4′, g5, g6 + унаследованных.

## A2.8 Характеризация (не гейтует; пред-декларация)

Уровневая аттрибуция граф-блока на негативной evidence-массе (важности/
сплит-статистика; ΔBA поверхностей full vs ablated на evidence-негативах).
**Пред-декларация**: результат отвечает ТОЛЬКО на вопрос специфичности
(«помогает ли граф отклонять hard-негативы зоны минта»), НЕ на вопрос
детекции дубликатов. Пишется в run-log и watchlist-отчёт.

## A2.9 Watchlist — дрейф-монитор (замена триггера прега §5)

Триггер «доля эвиденс-записей в проде» дополняется дрейф-переписью зондом
census (скрипты переписи воспроизводимы): **reopen при ≥ 30 dup-пар с
ненулевым граф-вектором**. Механизмы появления такой пары: правка тела
связанной пары (окно подтверждено: `manager.update` принимает `content`),
кросс-языковой минт, движковое сшивание/бэкфилл пере-сохранений (фича-запрос
D). Reopen = owner decision через новый прег.

## A2.10 Не меняется

Пороги g1–g6 §4 (g4 заменяется g4′ отдельной позицией ратификации);
экзамен v42-276; фиче-контракт 13+5; single-shot; ML-ONLY; sealed-holdout
дисциплина; правило «изменение после ратификации = аннулирование».
