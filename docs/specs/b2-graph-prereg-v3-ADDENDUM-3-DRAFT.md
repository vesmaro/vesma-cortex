## A3.1 Правило плато-исключения (уточнение зонированной лестницы v2)

Шаг косинусной лестницы монотонности (`ladder_ps[i] ≥ ladder_ps[i+1] − tol`,
лестница (1.0, 0.99, 0.95, 0.8, 0.5); шаги со стартом строго выше
`RAZOR_ZONE_COS_LOW = 0.95` не контролируются — как в v2) проверяется с
допуском:

- **1e-4**, если **обе** точки шага ≥ 0.99 (глубокое плато: обе точки выше
  границы решения 0.5, обе стороны шага — «dup»; инверсия в плато решения
  модели не меняет);
- **1e-6** (без изменений) во всех остальных случаях, включая любой шаг с
  точкой < 0.99 (напр., 0.80→0.50).

Двусторонняя razor-охрана НЕ меняется: fact-edit twin < 0.5,
near-boundary, unrelated, self-pair, envelope — все константы v2 на месте.
Sanity v2 остаётся 9/9 hard и исполняется на ОБОИХ моделях (конвенция
линии, раннер `phase1_sanity([full, ablated])` — ревизии 1.n/1.n+1).

## A3.2 Обоснование — механизм (диагноз NA, 23.10; верифицирован TL по коду)

- Ступень 0.95→0.80 лежит в зоне policy-константного класса пробы
  (косметический близнец = duplicate при любом измеренном cos, политика
  v1.1 §8.2): истинная ΔP ступени = 0, плато структурно, а не дефект.
- Замороженный допуск 1e-6 на высоте плато ≈ 0.006 raw
  (dP/dz = A·P(1−P) ≈ 1.9e-4 при A=0.9367); листовой джиттер ансамбля на
  этой ступени 0.07–0.29 raw (замер по деревьям на трёх корпусах:
  v4.4-orig +5.6e-05 RED / v44-r2 −8.6e-05 GREEN / v4.5 +1.15e-05 RED) —
  допуск в 12–50 раз ниже шумового пола рецепта; знак суммы — жребий
  состава, не здоровье модели.
- Нулевая историческая цена: ни один реально пойманный дефект сьюта
  (b2p-v41 near_boundary 0.0261 и fact_edit 0.7205; rev1n attempt 1
  fact_edit 0.7205) не был плато-инверсией; цикл v4.4-orig с красной
  монотонностью (+5.6e-05) был красным одновременно по fact_edit —
  плато-исключение не пропустило бы сломанную модель.
- Гипотеза «dose на позитивах» и «масса доборов» отведены NA как
  корневая причина (триггер перетасовки жребия — да; механизм — нет).
