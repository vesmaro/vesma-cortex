## 2. Объектив: варианты инъекции граф-контекста

Обозначения: u, v — записи; e(u,v)=1 — формальное ребро; cos — косинус
энкодера; τ_dup = 0.97 (верхняя граница dup-зоны, константа is-duplicate);
FR-* — таксономия framing §7.1.

### (A1) Мультитаск-контрастив на рёбрах с зона-сохраняющими маржинами

**Механика.** Три члена лосса на одной геометрии:

1. `L_rel` — рёберный контрастив с **односторонним насыщающим хинджем**:
   `L_rel = max(0, τ_rel − cos(u,v))²` на парах-позитивах из рёбер.
   Механика против стягивания dup-зоны (прямой ответ на вопрос реестра R1):
   градиент **равен нулю** при cos ≥ τ_rel — позитив тянет пару только до
   цели «достаточно близко», никогда «до единицы». τ_rel = 0.92 (нижняя
   граница зоны похожести; MLC 28.10/N1 — ратифицировано: из семантики
   ценза, до пилота, в тюнинг-сетку не входит; §10-в.1): пары-рёбра,
   уже сидящие ≥0.92 (~84 %
   позитивов; 16 % ниже 0.92 — факт манифеста MLC), получают нулевую тягу.
   Обучение давит ТОЛЬКО туда, где косинус недобирает относительно
   формального родства. (MLC 28.10/N1: точная формулировка гарантии —
   «L_rel не даёт рёберной тяги парам при cos ≥ 0.92»: нулевая тяга —
   свойство самого хинджа на конкретной паре; гарантия на всю геометрию
   dup-зоны «по построению» не заявляется — её дают совместно L_neg-квоты,
   dup-якорь и KD-реплей, и она проверяется измерением, а не словами.)
2. `L_dup` — **dup-якорь**: `max(0, cos(u,v) − τ_dup)²` на выборке пар
   FR-N-hard (0.92–0.97 без эвиденса) — «не поднимать выше 0.97 то, что
   движок различил»; плюс **preservation-член** на реальных seed-dup парах
   (68 пере-сохранений, нулевой граф-вектор, все NOT-эвиденс): не опускать
   ниже их прод-значения минус маржа. Якоря — формальные предикаты, не слова.
3. `L_KD` — **KD-реплей-якорь** к прод-векторам (посрезовая MSE 64/128/256/384
   с L2-ренормализацией, рецепт r5) на широком реплей-миксе (§5). Это главный
   зона-сохраняющий механизм: вся геометрия, кроме явно адресованных рёберных
   пар, привязана к прод-геометрии; оверсэмплинг пар зоны [0.92, 1.0] в миксе
   (вес, ратифицируемый в составе; DE 28.10/В5: ≥ 30 %) защищает территорию
   is-duplicate дополнительно.
4. `L_neg` — **негативный член** (MLC 28.10/N1 = DE 28.10/В2, одна
   формулировка): semi-hard бэнд-мининг негативов n к позитивной паре (u, p)
   из полосы `[cos(u,p) − 0.05, 0.97)` («почти как позитив, но вне
   dup-зоны»), `L_neg = Σ max(0, cos(u,n) − cos(u,p) + m)`, m = 0.05;
   обновление мининга раз/эпоху; квоты ЗАМОРОЖЕНЫ до ратификации:
   FR-N-hard ≤ 3–4× позитивов, FR-N-far 1–2×, **FR-X = 0 и FR-Q = 0 —
   ассерт**. In-batch-негативы остаются фоном поверх квоты. Манифест
   тренинга несёт гистограмму бэндов минированных негативов по эпохам;
   pair-ассерт: минированный негатив ≠ masked-пара и не пара с
   dup-партнёром (hash-уровень, §5.2). (MLC 28.10/N6: FR-X входит ТОЛЬКО
   в KD-сохранение — MSE к прод-векторам, член 3; нигде не входит в
   L_rel/L_dup/L_neg.)

Итого: `L = L_KD + λ_rel·L_rel + λ_dup·L_dup + λ_neg·L_neg`; сетка λ
(без τ_rel, N1) — пилотом на TR-VAL до полного прогона (§5.1; прецедент
r5-пилот), селекция только по TR-VAL (MLC 28.10/N5), фиксация в run-log
до полного прогона.

**Данные.** Позитивы: рёбра снапшота после гигиены минус маска (§5).
Негативы: квоты L_neg (член 4). Якоря: seed-dup + FR-X-сэмпл (только KD-член,
N6) + реплей-микс. Честный объём: рёбер 1 844 — на порядок ниже
контрастив-корпусов r5–r7 (25k+ пар); компенсация — in-batch-негативы
(каждое ребро создаёт O(batch) пар) + L_neg-квоты; KD-якорь не требует
пар-меток. Арифметика бюджета пар — §5.1 (DE 28.10/В1). Оценка сигнала —
characterization (§6).

**Сдвиг геометрии:** умеренный (полный тренинг энкодера; KD-якорь ограничивает
радиус дрейфа, но не обнуляет его).

**Риск для v42:** прямой — новые векторы = новый пин = полный CORTEX-E-PIN (§7);
raw-v42 на новой геометрии ожидаемо просядет (это измеряет leg-raw §4).

**Стоимость:** лайны 21h-класса (прецедент r8: 21h20m, zero kills); 2–4
CPU-дня лайнов; календарно см. §8.

### (A2) Adapter/LoRA-дообучение замороженной базы

**Механика.** База — веса прод-семейства (30M-класс, fp-преемник round-3 из
training-репо). Преемственность fp-базы к прод-артефакту — поимённый ассерт
(MLC 28.10/N4): sha-пин родителя из training-манифеста, либо векторная
fidelity fp-базы vs прод-ONNX на пробе (класс r5-экспорта, cos ≥ 0.999);
при init-from-student — отдельный аддендум + повторный пилот ранга (§11).
Тренируется низкоранговый адаптер (LoRA, ранг из пилот-сетки)
при замороженной базе; объектив — тот же (A1); экспорт = merge → dynamic int8
(рецепт r5/6/7, проверен cos 0.9994 к fp32; static int8/fp16 запрещены).
Против r8-ломкости: полный FT harrier дал кросс 1.0→0.9694 после 4 эпох и
кандидата 0.7417; LoRA ограничивает число степеней свободы сдвига геометрии
тем же механизмом, каким r8-урок диагностировал болезнь.

**Честная оценка «параллельного индекса без пере-эмбеддинга»** (поставлено
брифом): adapter меняет ФУНКЦИЮ энкодера — каждый вектор стора в новой
геометрии ≠ старому; старый индекс для новой геометрии нечётен. Вариант
«параллельный индекс» означает: старые векторы остаются каноническими
(is-duplicate не тронут — pin-налог на is-duplicate НЕ платится), новая
геометрия обслуживает второй индекс поиска. Цена: (а) двойное эмбеддинг-
умножение на записи (два инференса); (б) движковая волна второго индекса
(та же, что у опции D); (в) постоянный архитектурный форк «поиск живёт в
фьюжн-геометрии, дедуп — в базовой» с навсегда разделённой атрибуцией.
Вердикт честной оценки: **параллельный индекс = экономика D при худшем
рантайме и худшей атрибуции** — если платить двойную геометрию, D делает это
малой головой вместо второго полного энкодера. Поэтому параллельный индекс
**отвергается как дефолт** (возврат — только явным решением владельца, §10);
pin-налог при ADOPT платится полным планом §7. LoRA при этом остаётся
ценным как РЕЖИМ ТРЕНИНГА (ограничитель ломкости), независимо от деплой-формы.

**Данные / сдвиг геометрии / риск v42:** данные те же (A1); сдвиг — малый–
умеренный (ранг-кап); риск v42 тот же по структуре (новый пин), меньше по
амплитуде. Вариант init: (i) прод-база round-3 — чистая атрибуция, чистый mono-
якорь (рекомендуется); (ii) init от r6/r7-класса чекпоинта (кросс R@5 0.9556,
REJECT которого — артефакт cosine-рамки, но mono-en −0.0191 на свежем материале
— реальная эрозия) — только по мягкому триггеру characterization (если
прод-init не двигает primary на val), pre-registered.

**Стоимость:** лайны легче полного FT — консервативно планируются в том же
потолке r8-класса (MemoryMax 14G), фактический порядок 5–15 ч/лайн.

### (A3) Структурный вспомогательный loss (общие соседи / степени)

**Механика.** Вспомогательный член, предсказывающий структурные величины пары:
наличие/число общих рёберных соседей (cn — формальный предикат снапшота) как
бинарная/регрессионная голова, опционально triplet по 2-hop структуре.
Сигнал чисто структурный: «граф-прайор» в геометрии без контентного
контрастива.

**Честная роль:** самостоятельным объективом слаб — 1 844 рёбер дают тонкую
cn-структуру (средняя степень ~4.1); как **aux к A1/A2 с малым λ_struct
(pre-registered)** — регуляризатор, чей вклад измеряется ablation-ногой
(с-aux vs без-aux), а не верой. Не вносит собственный конфликт с dup-зоной
(не тянет контентные пары вместе), риск v42 минимальный.

**Стоимость:** маргинальная над A1/A2 (одна голова + член лосса).

### Рекомендация

**Ратифицированный объектив (MLC 28.10 — §10-в.1): A2-режим (LoRA на замороженной прод-базе,
init-прод) × A1-лосс (насыщающий хиндж τ_rel=0.92 + негативный член L_neg с

оверсэмплингом зоны) + A3-структурная aux как низковесная pre-registered нога
(вклад меряет ablation).** Обоснование: что учить — определяет A1 (единственный
из трёх, прямо адресующий родство через формальные метки с механикой защиты
dup-зоны — нулевая тяга хинджа при cos ≥ 0.92 плюс L_neg-квоты, N1); как не
повторить r8-ломкость — определяет A2 (ранг-кап
вместо полного FT — прямой ответ на измеренный отказ); чем регулялизовать —
A3. Полный FT как arm не пред-регистрируется (r8-урок); init от r6/r7 — только

только-KD).

**Итог по обе стороны честно.** В пользу попытки: два из «потолков» —
калибровочные дефекты рамки, а не модели; поверхность сигнала другая
(структура рёбер, не переводы); объём данных для KD-якоря достаточен.
Против попытки (объявляется измеряемым риском, не скрывается): главный
остаточный риск — **информативность рёбер как меток** (потолок задают данные —
механизм переносится): lift ограничен долей рёберного сигнала, ортогонального
косинусу, и она тонкая по переписи (0.19 % зоны, 16 % позитивов ниже 0.92 —
это ~289 рёбер, ~240 после гигиены). Ограничение глубже (DE 28.10, риски):
метки круговые — 100 % рёбер рождены auto-dedupe, т.е. «родство» частично
определено тем же косинусом, который попытка улучшает; действительно
информативный сигнал — только у позитивов ниже 0.92 (~289 / ~240
пост-гигиены); K2-пермутация (§4.3) замеряет ровно это — сигнал рёбер сверх
жребия состава.
Попытка спроектирована так, что этот риск замеряется characterization'ом
ДО тяжёлых лайнов (K1/K2 §6) и forecasting-полосами П6 (§6) — владелец
получает фальсифицируемый прогноз, а не надежду.

## 4. Исправленная рамка оценки

**Первичная: PA-Q1 retrieval-form** (вердикт АрхКома 20.10; прецедент
r7-confirm, где retrieval-превосходство генерализовалось, а косинусные
охранные — нет). Две запечатанных поверхности, правило «обоих наборов»
наследуется binding'ом: PASS на обоих = ADOPT; иначе REJECT финален.

### 4.1 Что уходит и почему

Bootstrap-константы: paired bootstrap по запросам, B = 10 000 ресэмплов, seed

**(п1) Первичная полоса Δrecall@5 (fusion − prod, masked-лег): [−0.01, +0.07]; точка ≈ +0.01 (+0.00…+0.02).**
Арифметика (n = извлекаемые masked ≈ 215–305, точка 260):
- страта «жёстких» позитивов cos < 0.92 — ~16 % ценза → n_H ≈ 34–49;
- addressable-промахи прода на жёсткой страте (прод не поднимает пару в
  top-5): q_H,prod ∈ [0.5, 0.8] (зависит от плотности пула дистракторов) →
  8–24 запроса;
- восстановление фьюжном — обобщённая рёберная тяга (LoRA-кап + KD
  ограничивают): r ∈ [0.3, 0.9] → wins ≈ 3–22;
- потери на «лёгкой» страте (cos ≥ 0.92; KD-ограничены): ≤ 2–3 % →

- Δ = (wins − losses)/n. Нижняя кромка: (3 − 7)/305 ≈ −0.01; верхняя —
  согласованный угол q ≤ 0.55, r ≥ 0.85, losses ≤ 2, n → 305: ≈ +0.07.

Power-проверка «не тривиально широкая» (критерий поимённо, MLC 28.10):
детекционный пол paired bootstrap для дискордантной структуры — 2×CI95 ≈
3.92·√(wins+losses)/n; при losses → 0 минимально обнаружимый lift = 3.92²/n =
0.050–0.072 (n: 305→215). Ширина полосы 0.08 ≤ 1.5 × пол@215 (0.107) — полоса
одной детекционной единицы. **Критерий подтверждения (п1):** измеренная точка
Δ ∈ [−0.01, +0.07] → прогноз CONFIRMED; вне полосы → публикуется NOT
CONFIRMED, без перезаписи.

**Пре-декларированный прогноз исхода g_rel (честно, до прогона):** гейт
Δ ≥ max(2×CI95, δ_rel) достигаем только в правом-верхнем углу полосы —
wins ≥ 15–17 при losses ≤ 3 (n → 305); @215 гейт достижим только в углу
прогноза-макс (losses ≈ 0). Внутри точечного прогноза CI-нога лежит ВЫШЕ
лифта → наиболее вероятный исход по прогнозу — «REJECT по CI-ноге» либо STOP

смягчение: δ/допуски ратифицированы (в.3), пересмотр — только новой
ратификацией MLC.

**(п2) Полоса BA leg-C (перекалиброванный v42): [0.930, 0.965]; точка 0.945–0.955.**

### 4.3 Kill-criteria (пре-декларированные, до прогона)

- **K1 (STOP, класс «данные»):** извлекаемых masked-позитивов в воронке <
  STOP-минимума ратификации (STOP-числа внесены — §4.2-П6; минимальные

  поддерживает гейт при этой ρ» ДО тренинга; тихой смены ρ нет (наследие
  MLC 28.10); делёж masked-лега ратифицирован — вариант (i), §10-в.4.
- **K2 (STOP, класс «сигнал»):** пол пермутации рёбер (retrain-включающий
  розыгрыш) ≥ δ_rel в characterization → «рёберный сигнал ниже шума состава
  на этом сторе» — попытка закрывается честно до тяжёлых лайнов. Это легальный
  владелеческий исход: реестр рисков конвертирован в измерение.
  (MLC 28.10/DE 28.10, В7: пермутация СТРАТИФИЦИРОВАННАЯ — шейффл партнёров
  внутри своего косинус-бэнда, не блочный; иначе пол замеряет жребий состава,
  а не отсутствие сигнала. Круговость меток — 100 % auto-dedupe; действительно
  информативны ~289 позитивов ниже 0.92 / ~240 пост-гигиены — именно их
  защищает стратификация.)
- **K3 (ABORT, класс «инструмент»):** NaN/дивергенция лосса, красный fidelity-
  preflight, расхождение byte-tripwire — печати не читаются, эскалация TL.
- **K4 (early kill, легальный):** leg-R raw-BA < катастрофического пола 0.90
  (ратифицировано — §10-в.3) → остановка до чтения печатей (v42-276 — стоячая экзаменационная
  поверхность с историей чтений, не запечатанный набор; экономит ресурс).
- **K5:** mono-прокси тренинга < порога → переключение расписания (KD-replay
  proportion ↑, r6-механика); binding меряется один раз на печатях (§4.1).
- **K6 (STOP, класс «селекция», MLC 28.10/N3):** на TR-VAL не осталось ни
  одного guard-feasible чекпоинта → именованный исход «нет guard-feasible
  чекпоинта на val»; печати не читаются — guard'ы чекпоинт не выбирают (§3),
  пустое пересечение есть легальное закрытие попытки.
- **K7 (STOP, класс «рамка», MLC 28.10/N3):** вакуумные допуски guard'ов —
  пол tol выше смысловой полосы метрики (формально tol ≥ 2× max пола, но пол
  сам шире разумного сдвига) → именованный исход «STOP: вакуумные допуски
  guard'ов»; допуски молча не расширяются и пост-фактум не сужаются — вопрос
  возвращается на ратификацию.

**Single-shot:** один прогон раннера на набор; re-roll после израсходованного
single-shot = отказ раннера (ML-STD-0003 П8); resume — только маркером с полным
повторным прологом. Read-дисциплина «no early-exit» (DE 28.10): α и β читаются
ЦЕЛИКОМ даже при красной α — re-roll через непрочтённый β запрещён. Пролог
П1–П9 дословно (swap_check → env → host →
byte_tripwire → activation → frozen_inputs → gate_start; декларация стоимости
П9; П9-бюджет-таблица λ-сетка × ablation × пилоты внесена — §8
(ратифицирована MLC 28.10, уточняется Фазой 0)). **Честный REJECT — полноденный исход
линии** (прецедент B2-канона); вердикт идёт владельцу, который и принимает
финальное решение отклонить/ухватить.

## 5. Данные: таксономия, гигиена, гейт-наборы

### 5.1 Формальная таксономия (директива 22.10: предикаты, не слова)

Классы FR-P / FR-N-hard / FR-N-far / FR-Q / FR-X наследуются из framing §7.1
предикатами дословно (тот же снапшот-механизм). Порядок сборки (MLC 28.10;
DE 28.10/В3 — расширен): **гигиена → классы → маска → ЗАМОРОЗКА материала
α/β (fp) → train/якоря/реплей на остатке** — запечатанная сторона режется
ПЕРВОЙ, тренировочные поверхности строятся только из остатка. «Свежий»
материал = записи, отмигрированные после D0; D1 (срез сборки наборов) и
окно источника фиксируются в преге. Temporal-рёбра окна (D0, D1] —
осознанно НЕИСПОЛЬЗУЕМАЯ в v1 поверхность (DE 28.10/В6; кандидат на
поверхность v1.1, не молча). Арифметика бюджета пар (DE 28.10/В1):
train-позитивов ~1050 (пост-гигиена, минус маска); KD ≥15k текстов
(проба 2–3k для λ-сетки; heritage-фонд 25k); свежий приток ~700–1000
записей за 1.5–2.5 недели — источник свежего материала α/β; пост-гигиенный
masked-пул ~305 (до гигиены ~370), после извлекаемости 215–305 —
см. §4.2-П6; делёж masked-лега ратифицирован (вариант (i)) — §10-в.4. Для тренинга эмбеддера добавляются роли:

| Роль | Предикат | В train | В гейтах |
|---|---|---|---|
| TR-POS-edge | FR-P после гигиены, minted ≤ D0, вне маски | позитивы L_rel | — |
| TR-POS-masked | FR-P, попавшие в seed-маску ρ=20 % (seed в преге) | **ЗАПРЕЩЕНО** во всех тренировочных ногах | g_rel/g_mrr (PRIMARY) |
| TR-NEG | FR-N-hard/FR-N-far квоты (заморожены: hard ≤ 3–4× поз., far 1–2×; FR-X = 0, FR-Q = 0 — ассерт, MLC 28.10/N1) | L_neg: semi-hard бэнд-мининг (§2, член 4) + in-batch | g_spec-класс страта |
| TR-ANCHOR | seed-dup пары (68, все NOT-эвиденс) + FR-X сэмпл | preservation/KD-цели (геометрия, НЕ семантика; N6: FR-X — только KD-член) | leg-R/leg-C v42-276 отдельно |
| TR-REPLAY | реплей-микс: heritage-корпуса embed-дуги (sealed TRAINING-поверхности r5 `e64fdbea…` / r7 `ad3d438f…` — легальное переиспользование: это тренировочные поверхности, не гейт-наборы) + сэмпл текстов стора с оверсэмплингом зоны [0.92,1.0] ≥ 30 % и обязательным покрытием dup-территории (тексты 130 дублей + партнёры FR-X); KD-проба 2–3k текстов для λ-сетки, полный реплей ≥15k (DE 28.10/В5) | L_KD | — |
| TR-VAL | именованная VAL-поверхность селекции (MLC 28.10/N5): гигиена ∧ FR-P ∧ ¬masked ∧ ¬record α/β, seed ρ_val; fp при сборке; свои полы в Фазе 1; дизъюнкт-ассерты val × train × якоря × α/β (hash, §5.2) | не тренируется (оценочная поверхность λ-сетки) | селекция чекпоинта/λ — ТОЛЬКО по TR-VAL; в финальных гейтах не участвует |
| FR-Q (карантин) | cn ≥ 1 без ребра | **НЕ тренируется в v1** (см. §10, вопрос 2) | вне гейтов |

**Специфика маски для эмбеддера (честно, отличие от B).** У ранжера B маска
cut-closure защищает граф-ФИЧИ (они вычисляются из рёберного графа). У
эмбеддера вход — тексты; утечка возможна только через ПАРУ: точная пара
masked-ребра не должна встречаться ни в одной тренировочной ноге (рёбра,
якоря, реплей-пары, heritage-корпуса — pair-level дизъюнктность ассертами
hash-уровня). Косвенный структурный вывод «концы masked-ребра сближаются,
потому что у каждого есть train-рёбра к общим соседям» — это НЕ утечка, это
ровно тот механизм link-prediction, который попытка и проверяет (transductive
структурный вывод — легитимная цель, не контаминация); это фиксируется в
преге словами, чтобы characterize-отчёт не пересчитывался задним числом.

### 5.2 Гигиена и дизъюнктность

Порядок data-contract §6 дословно: mode=ro → снапшот в /tmp → скан секретов
ДО экспорта → no-federate/quarantine → в репу только счётчики/фингерпринты;

поверхности v43/
v4.4; vs сожжённые наборы `cb367577…`/`r5_gate_v2` (их материал не попадает
ни в train, ни в новые наборы); vs манифесты heritage-корпусов r5/r7.

### 5.3 НОВЫЙ запечатанный гейт-набор (требования)

Сожжённые `cb367577…` и `r5_gate_v2` гейтами не служат. Строятся два набора,
формула и дисциплина — verbatim PA-Q1 + первичная нога:

- **Состав:** PA-Q1-страты (llm / real / twin; ратифицировано MLC 28.10 — §10-в.7: ~220 пар

  свежая генерация, разные
  seed'ы (оба в манифестах); независимы PA-Q1-страты, masked-нога общая

- **Требования (поимённо):** свежий материал = записи после D0 (В3), вне ВСЕХ

## 9. Взаимосвязь с B/D

- **B не зависит от эмбеддера** (прод заморожен ассертом): его цикл лёгкий
  (лайны минут-часов, LightGBM ~50 с/модель) и может идти параллельно
  A-дизайну/characterization календарно. **Тяжёлая ресурсная очередь — одна**:
  21h-лайны A занимают окно; B-обучение в том же окне не ставится (дисциплина
  «одна тяжёлая линия»), лёгкие B-лайны вне окон A допустимы.
- **При ADOPT A:** B/D переучиваются на новой геометрии дёшево — B: ре-экстракция
  фич (минуты) + refit бустинга (~50 с) + перепрогон своих гейтов на новой
  геометрии (печати своих циклов — свои/новые, не эти); D: перетрейн головы
  384→384 (минуты–часы). Движковое потребление обоих — их dependency-лист.
- **При REJECT A:** B/D не затронуты — асимметрия в пользу секвенции
  «A сейчас, B следом за вердиктом».
- Guard-крас кандидата A на свежем наборе при зелёном первом = REJECT по
  правилу обоих наборов (§4); «ADOPT с флагом» для A не вводится — энкодер
  либо готов к pin-поезду, либо нет.

## 10. Ратифицированные параметры (MLC 28.10)

Коррекция процесса (владелец, 28.10): методологические параметры — объектив,
пороги, схемы проверок — ратифицирует MLC (прецедент 24.10 «как комитет
утвердит, так и поступим»); владельцу — финальный вердикт линии после
single-shot. Формат: «в.N: параметр — ратифицирован MLC (основание: ...)».

- **в.1: Объектив — ратифицирован MLC** (основание: ml — A2-LoRA как
  измеренный ответ на r8-ломкость, N1-формализация лосса; de — В5-состав
  реплея). Составной: LoRA-режим (A2, init-прод; init-r7 — только по мягкому
  триггеру characterization, pre-registered) × A1-лосс (насыщающий хиндж
  τ_rel = 0.92 — ратифицирован из семантики ценза, вне тюнинг-сетки;
  L_neg с замороженными квотами, N1; dup-якорь; KD-реплей с оверсэмплингом
  зоны ≥ 30 %) + структурная aux (A3) низковесной pre-registered ногой.
  Полный FT не пред-регистрируется.
- **в.2: FR-Q как тренировочные позитивы — ратифицирован MLC** (основание:
  ml — квота FR-Q = 0 ассерт (N1); директива 22.10 — спорное не размечается
  молча). v1 = НЕТ; опциональная нога v1.1 — только отдельной ратификацией MLC.
- **в.3: δ-константы и допуски — ратифицированы MLC** (основание: ml —
  формулы от полов characterization, N3; **замечание комитета:** если пол
  characterization даст δ выше смысловой — STOP K7 «гейт непосилен», не
  тихое смягчение). δ_rel = 0.02; δ_mrr = 0.01; δ_abl = 0.01 — порог
  измеримого вклада члена в ablation-матрице (вклад ≥ max(2×CI-пол TR-VAL,
  δ_abl)); tol_mono класс 0.005 (финал от полов Фазы 1); g_total ≥
  прод_на_наборе + 0.02 (формула владельца 22.10 — ратифицированный класс);
  G2-флоры real ≥ 0.90 / twin ≥ 0.95 / seed-dup ≥ 0.90 с pre-registered
  правилом ре-якоря к прод_на_наборе до прогона; K4-пол leg-R 0.90.
- **в.4: Masked-лег α/β — ратифицирован MLC** (основание: de — В1-арифметика
  ~305 / 215–305; ml — сохранение ρ = 20 % и силы гейта). **УТВЕРЖДЕНО:
  вариант (i)** — одна общая декларированная masked-популяция в обоих
  наборах; правило «обоих наборов» реально действует на PA-Q1-стратах;
  не-независимость masked-лега декларируется в преге словами (§5.3).
- **в.5: Бюджет попыток — ратифицирован MLC** (основание: de —
  read-дисциплина «no early-exit»). ОДНА single-shot; два запечатанных
  набора (α+β) читаются одним прогоном раннера, PASS на обоих = ADOPT,
  иначе REJECT финален (наследие правила владельца 22.10); K1/K2 — легальные
  досрочные закрытия до тяжёлых лайнов, K6/K7 — до печатей; β читается
  целиком даже при красной α. П9-бюджет-таблица внесена — §8 (уточняется
  Фазой 0).
- **в.6: Pin-план при ADOPT — ратифицирован MLC** (основание: ml/de — leg-C
  дисциплина N2, no-harm через перекалибровку внутри попытки). Полный
  CORTEX-E-PIN по §7; no-harm binding = перекалиброванный v42-корридор
  (BA ≥ 0.9449 − max(tol; CI95)) с дисциплиной leg-C (дизъюнктность
  refit-корпуса × 276, заморозка рецепта до чтения 276 — тюнинг порога на
  276 = вердикт-фиттинг, контроль воспроизводимости на старой геометрии);
  raw-v42 = monitored; параллельный индекс отвергнут как дефолт.
  **Единственный владелец-уровневый элемент (уведомление, не вопрос):**
  pin-налог 4–7 дней стены при ADOPT (2–3 дня вне очереди линии) — владелец
  уведомляется при ACTIVATED-записи TL, и его оценка входит в его
  окончательное решение по вердикту ADOPT.
- **в.7: Рамка гейтов — ратифицирована MLC** (основание: ml — retrieval-form
  PA-Q1 первичная, анти-уроки r7-confirm; de — поимённые полосы/STOP,
  В4/В7). Косинус-гейты embed-эпохи уходят (llm-поверхность — только
  monitored); mono per-direction, дифференциальный max_rank, total ≥
  прод+0.02 — binding; абсолюта выше значения прода на свежем населении
  не осталось нигде (анти-урок r7-confirm B). П6-полосы внесены поимённо
  с power-арифметикой (§4.2-П6); полосы не тривиально широкие — ширины
  ≤ 1.5× детекционных полов. Продуктовые константы g_lat ≤ 45 ms /
  g_size ≤ 60 MB — ратифицированы в составе рамки.
- **в.8: Ресурсное окно — ратифицировано MLC** (основание: iron rules 28.10
  без возражений комитета; Sys — на фазе исполнения, E-лист фьюжна).
  21h-класс лайны с потолками MemoryMax 14G / SwapMax 16G / CPUQuota 800 %,
  детач от zcode, последовательность, swap_check первым событием.

## 11. Открытые вопросы и зависимости (не блокируют ратификацию рамки)

- fp-преемник весов прод-семейства для LoRA: наличие fp32/чека в training-репо
  верифицируется Фазой 0 вместе с ассертом преемственности (MLC 28.10/N4:
  sha-пин родителя из training-манифеста, либо векторная fidelity fp-базы vs
  прод-ONNX на пробе); если fp-весов нет — init от последнего студента
  embed-дуги становится единственным путём, и это меняет атрибуцию (отдельный
  аддендум + повторный пилот ранга ДО ратификации рецепта, не молча).
- Судьба ретро-таблицы retrieval-формы embed-дуги (обещана брифом 19.10) —
  не блокирует; её метрика может стать дополнительным monitored-сигналом.
- Числа стора — точка 28.10; при сборке корпуса — свежий снапшот с fp и
  пересчитанными каунтами (L6 framing).
- Движок занят волнами ADR-0049: потребление при ADOPT — волна parity в
  движковой очереди (§7), никаких движковых работ из линии.

## 12. Изменения по MLC 28.10 (сессия A-retrial)

Интеграция правок ML-члена (N1–N7) и датасет-члена (В1–В7); где правка
противоречила тексту — побеждал комитет. Формат: было → стало.

- **N1 — негативный член лосса.** Было: негативы заявлены в данных
  («in-batch + hard-negative mining из FR-N-hard»), в формуле L отсутствовали.
  Стало: формализован член 4 `L_neg` (§2) — semi-hard бэнд-мининг из
  `[cos_pos − 0.05, 0.97)`, обновление раз/эпоху, замороженные квоты
  (FR-N-hard ≤ 3–4× позитивов, FR-N-far 1–2×, FR-X = 0 и FR-Q = 0 — ассерт);
  формула `L = L_KD + λ_rel·L_rel + λ_dup·L_dup + λ_neg·L_neg`; манифест
  тренинга несёт гистограмму бэндов минированных негативов по эпохам;
  pair-ассерт «минированный негатив ≠ masked-пара и не пара с dup-партнёром»
  (§5.2). Формулировка хинджа: было «геометрия dup-зоны не получает рёберной
  тяги по построению»; стало — «L_rel не даёт рёберной тяги парам при
  cos ≥ 0.92» (точное свойство хинджа; полная гарантия — совместная, через
  квоты/якорь/KD, и измерением). τ_rel = 0.92: было PROPOSED в составе
  тюнинг-сетки λ/τ; стало — ратифицировано из семантики ценза до пилота,
  в сетку не входит (финализировано 28.10).
- **N2 — leg-C дисциплина.** Было: g_nharm одним предложением в таблице
  гейтов. Стало (§4.2): поимённый ассерт дизъюнктности refit-корпус ×
  v42-276 = 0; рецепт refit (включая процедуру выбора операционного порога)
  заморожен ДО чтения 276 — тюнинг порога на 276 = вердикт-фиттинг, запрещён
  словами; контроль воспроизводимости — refit тем же рецептом на СТАРОЙ
  геометрии обязан воспроизвести коридор 0.9449 в допуске, иначе красный
  leg-C = класс «инструмент», не гейт.
- **N3 — kill-исходы.** Было: K1–K5. Стало: K1–K7, добавлены именованные
  исходы «нет guard-feasible чекпоинта на val» (K6) и «STOP: вакуумные
  допуски guard'ов (пол tol выше смысловой полосы)» (K7) (§4.3).
- **N4 — преемственность fp-базы.** Было: «fp-преемник round-3 из
  training-репо» без ассерта. Стало: поимённый ассерт преемственности к
  прод-артефакту — sha-пин родителя из training-манифеста либо векторная
  fidelity fp-базы vs прод-ONNX на пробе; при init-from-student — аддендум +
  повторный пилот ранга (§2-A2, §11).
- **N5 — именованная VAL-поверхность TR-VAL.** Было: «сетка λ/τ — пилотом
  на val» без именованной поверхности. Стало: TR-VAL с предикатом
  (гигиена ∧ FR-P ∧ ¬masked ∧ ¬record α/β ∧ seed ρ_val), fp при сборке,
  своими полами в Фазе 1, дизъюнкт-ассертами val × train × якоря × α/β
  (hash); селекция чекпоинта/λ-сетки — ТОЛЬКО по TR-VAL (§5.1 таблица,
  §4.2, §6, §8).
- **N6 — роль FR-X.** Было: FR-X упомянут в якорях без ограничивающей
  формулы. Стало: FR-X входит ТОЛЬКО в KD-сохранение (MSE к прод-векторам),
  нигде не входит в L_rel/L_dup/L_neg (в последней — квотой 0) (§2, §5.1).
- **N7 — скоупы и ассерты.** Было: n-gram zero-tolerance «против всех
  известных training-поверхностей» (включая сожжённые — риск
  ретро-сожжения). Стало: скоуп = ТОЛЬКО незапечатанные поверхности;
  ретроспективное расширение проверки на тексты v4.5/g4-spec-v1 пост-фактум
  = сожжение, запрещено заранее словами (§5.2, §5.3). Добавлены:
  anchor-68 × α/β = 0 поимённым ассертом; минимальные каунты на каждую
  страту α/β со STOP-веткой; три роли чтения v42-276 (K4 → leg-R monitored
  → leg-C binding) зафиксированы в преге заранее (§4.2, §4.3, §5.2, §5.3).
- **В1 — арифметика masked-лега.** Было: «~370 @ ρ=20 %, после гигиены
  пересчитывается». Стало: полный пост-гигиенный masked-пул ~305 (370 —
  цифра до гигиены), после извлекаемости 215–305; делёж на два независимых
  лега решением молча запрещён — вынесен на ратификацию:
  (i) одна общая декларированная masked-популяция в обоих наборах (правило
