## 5. Исходы

- **ADOPT** → engine-интеграция отдельной волной: CanonState graph-evidence
  (OQ-3, аддендум ADR-0004), VesmaProvider rev 1.n, release parity движка.
- **REJECT** → ревизия не выпускается; граф-блок остаётся в watchlist с
  триггером пересмотра «доля эвиденс-записей в проде» (пересчёт зондом).
