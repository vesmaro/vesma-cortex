# Prereg ROUND-7 vesma-embed — качество llm-класса (2026-10-10, ДО прогона)

> Статус: **ACTIVATED**. Владелец ратифицировал 10.10: round-7 = расписание
> round-6 БЕЗ изменений + единственная переменная — **качество llm-класса**
> (пере-перевод более сильным переводчиком). Мотивация: llm-класс закапан
> ~0.89–0.91 во всех режимах обучения (r4/r6ep4/r5) — потолок задают сами
> пары, не модель. Изменение порогов/population после прогона =
> аннулирование.

## 1. Наследуется из round-6 без изменений

Расписание (фаза 1 KD-якорь → фаза 2 контрастив λ=1.0/τ=0.05 с mono-guard
0.8932, KD-replay ≥1:3), селекция mono-guard-aware (§3 round-6), экспорт
dynamic int8, пороги гейтов (seed-dup 0.85/0.50; llm 0.93/0.90; gX0 0.005;
g1 0.9252; g6a 45ms; g7 60MB), population = гейт-набор `cb367577…` +
мониторы, single-shot дисциплина.

## 2. Дельта round-7 — данные

- **llm-класс пере-переводится**: все 1617 строк `translated-llm-r4` (и
  производные twin'ы) — учителем **Qwen3-1.7B-Instruct** (Q8_0, локально;
  загрузка по hf_token при необходимости). Остальной корпус — без изменений
  от fp `e64fdbea…` минус гейт-исключения.
- Гейты качества пар — как в round-4/5: digit-preservation на каждой паре,
  teacher-cos ≥0.55, анти-копия; A-серия ассертов сборки (включая
  n-граммовый zero-tolerance на новом материале — урок round-5).
- **Не смешивать поколения**: старые llm-переводы 0.6B полностью заменяются
  (не доливаются); 0.6B-переводы real/seed/twin классов остаются.
- Новый corpus fingerprint + double-run; популяция ≈ 26.6–26.8k (отчёт exact).

## 3. Параллельная research-lane (не влияет на round-7 прогон)

Teacher-sweep: свежие малые (≤1B) мультиязычные эмбеддеры (релизы после
середины 2025) → аудит харнесом фазы-0 (144 пары медиана ≥0.90 + mono-зонд
|Δ|≤0.005 + гейт-набор S_cal/медиана/R@5). Результат = вход возможного
«Учитель»-плеча round-8 (отдельный прег). В round-7 учитель НЕ меняется —
чистая атрибуция «качество данных».

## 4. Гейты и исходы

Без изменений к round-6: single-shot на финальном артефакте (dynamic int8),
binding = g1 ∧ gX0 ∧ seed-dup ∧ llm ∧ g6a/g7. **Исходы**: ADOPT →
cortex-recalib → release-parity; **REJECT — финальный**: исчерпаны рычаги
данных (round-5 scale + round-7 llm-качество), расписания (round-6) и
селекции. «llm-класс ниже 0.93 при качественных парах + защищённом mono»
фиксируется как платформенное ограничение. Round-8 не планируется.
