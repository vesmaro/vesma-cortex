# Методология оценки vesma-cortex v1.0

- **Статус:** Accepted (v1.0, полузаморожена: пороги меняются только
  аддендумом-пререгистрацией через `gate_contract.json` — §6; решение
  АрхКома MR0, [ADR 0003](../decisions/0003-model-artifacts-release-and-eval.md))
- **Дата:** 2026-10-03
- **Область:** чем и как оценивается модель — реестр метрик, бейслайны,
  три слоя оценки, таблица гейтов, локбокс, классы проб, правила
  пререгистрации. Основа — препрег v2 (canon) и урок #480: holdout-метрики
  слепы к дефектам, которых нет на поверхности оценки.

## 1. Реестр метрик

| Метрика | Формула / правило | Инструмент | Слой | Владелец |
|---|---|---|---|---|
| balanced accuracy (BA) | (sens + spec) / 2 | `sklearn.metrics.balanced_accuracy_score` | A, B, локбокс | TL |
| sensitivity / specificity | TPR / TNR на holdout | sklearn | A, B | TL |
| Brier | `brier_score_loss` | sklearn | A, B | TL |
| типизированность | доля ответов с валидным `Noul`+`Score` | runner | A, B | TL |
| self_pair | P(dup \| проба против себя, cos=1.0), порог ≥ 0.9 | sanity-сьют (`cortex.eval.sanity`) | A | TL |
| near_boundary | P(dup \| лёгкая пертурбация, cos≈0.99), cut ≥ 0.5 | sanity-сьют | A | TL |
| unrelated | P(dup \| разные темы, cos=0.578), потолок < 0.5 | sanity-сьют | A | TL |
| monotonicity | нестрогое невозрастание P по cos-лестнице {1.0, 0.99, 0.95, 0.8, 0.5}, tol 1e-6 | sanity-сьют | A | TL |
| bundle_integrity / feature_contract | sha256 байтов и порядок фич == манифесту == замороженному контракту | sanity-сьют | A | TL |
| prev_adopt-коридор | BA(release) ≥ BA(prev ADOPT) − max(0.02; CI95) | runner | A (release), B | TL |
| delta-rate | доля решений, где вердикт модели ≠ вердикту базлайна | B0-коллектор (`telemetry/metrics-2h.jsonl`) | B0 | SRE |
| no-harm в cos-полосе | доля расхождений модели с базлайном при cos ≥ 0.95 | B0-коллектор | B0 | SRE |

Пороги всех коридорных/инвариантных метрик фиксируются не в этом тексте,
а в `gate_contract.json` (§6) — источник значения для CI.

## 2. Бейслайны

- **Косинус 0.92 — первичный** (`DeterministicProvider` движка): порог
  препрега v2; всякая калибровка обязана показать BA строго выше него
  (ADOPT-условие 5).
- **prev_adopt — коридорный**: BA предыдущей ADOPT-ревизии — пол для
  release-гейта (§4). Ловит деградацию при перекалибровке; ранжированием
  близких ревизий не занимается (см. оговорку §4).

## 3. Три слоя оценки

### Layer A — CI-синтетика

- Два замороженных набора: **merge-набор ~60 пар** (быстрый, каждый PR) и
  **release-набор ≥ 200 пар** (стратифицированный, на release-гейте).
- Тексты проб коммитятся в репу (`tests/evalsets/<set-id>/`: `probes.jsonl`
  + `manifest.txt`) — синтетика, публичность разрешена
  [ADR 0003](../decisions/0003-model-artifacts-release-and-eval.md) R2;
  набор фингерпринтится — `eval_set_sha256` в отчёте прогона.
- **Пары ВСЕГДА считаются через `cortex.features.pair.features`** — урок
  #480: локальные копии фичевой математики расходятся с прод-обёрткой в
  порядке колонок, и сюит начинает мерить не тот артефакт.
- Сюит (`scripts/eval_sanity_suite.py`) — инструмент инвариантов и
  коридоров Layer A; прогон против бандла (dir или .onnx), exit ≠ 0 = провал.

### Layer B — калибровка по препрегу v2

Single-shot holdout по замороженному препрегу (canon): 7 стратов,
holdout 30 %, шесть условий ADOPT. Holdout сжигается одним прогоном;
исключение для реэкспорта неизменных весов — §6. Итог Layer B — вердикт
ADOPT/DECLINE/NO-DATA в `eval-results.json`.

### Layer B0 — поле

Прод-телеметрия по [плану B0](../experiments/b0-telemetry-plan.md):
delta-rate, no-harm-коридор cos-полосы, счётчики `CORTEX-E-*`. Поле —
источник правды о ценности, не гейт качества артефакта.

## 4. Таблица гейтов

| Слой гейта | Проверки | Блокирует | Оговорка |
|---|---|---|---|
| **ИНВАРИАНТЫ** | bundle_integrity; feature_contract (порядок фич == манифест == `FEATURE_NAMES`); типизированный выход; self_pair ≥ 0.9; монотонность (tol 1e-6) | **merge** | детерминированные: воспроизводимы бит-в-бит, флейта нет |
| **КОРИДОРЫ** | near_boundary ≥ 0.5; unrelated < 0.5; синтетическая BA ≥ prev_adopt − max(0.02; CI95) | **release** | коридор ловит **обрывы**, не ранжирует близкие ревизии: падение в коридор — повод для разбора, а не автоматический вердикт «хуже» |
| **ВЕРДИКТЫ** | метрики препрега-v2 (Layer B); delta-rate (B0) | **никогда** (информационные) | ADOPT/DECLINE — решение владельца по замороженному decision rule; delta-rate — критерий ценности B0, не качества |

Распределение инвариант/коридор — вердикт спора SRE vs Analyst
([ADR 0003](../decisions/0003-model-artifacts-release-and-eval.md),
«Позиции и споры»).

## 5. Локбокс (holdout вне всех коммитимых поверхностей)

- ~50 пар, **другие** сиды и темы — не пересекаются с merge/release-наборами.
- В репе — только хеш набора (`lockbox_sha256`); сами пробы не коммитятся.
- Одноразовый прогон на release-гейте; повтор по тому же набору запрещён
  механикой run-log (refusal при повторном фингерпринте —
  [data-contract](data-contract.md) §8).
- Назначение: последняя независимая поверхность перед публикацией;
  не заменяет Layer B.

## 6. Анти-HARKing: `gate_contract.json`

Гипотезы после того, как данные видны (HARKing), запрещены механикой:

- Пороги всех гейтов живут в `gate_contract.json`, файл версионирован и
  несёт **свой sha256**; значения пиннутся в этом документе и в CI.
- Контракт **не привязан** к `feature_set_sha256` (вердикт комитета:
  пороги грейдят модель, не фичи).
- Правило разделения: **PR с порогами не содержит артефактов, и наоборот** —
  смена правил и смена модели не едут одним вагоном.
- Порог меняется только аддендумом-пререгистрацией (до прогона оценки);
  повышение порога в merge-гейт — только директива владельца (прецедент
  таксономии инвариант/коридор/вердикт — ADR-0026 движка).
- Исключение Layer B для реэкспорта: если `weights_sha256` не изменился,
  holdout не сжигается — вместо него эквивалентность 1e-6 выходов на
  замороженном наборе.

## 7. Классы проб: таксономия слепых пятен (после #480)

| Класс | Что ловит | Статус покрытия |
|---|---|---|
| identity / self | инверсия self-пары (#480) | сюит, проверка (a) — инвариант |
| near-identity / близнец | обрыв на границе порога | сюит, проверка (b) — коридор |
| симметрия пары P(x,y) = P(y,x) | нарушение симметрии фичевого ядра | **сейчас НЕ тестируется** — хвост |
| монотонность | немонотонный отклик по косинусу | сюит, проверка (d) — инвариант |
| far-negative | ложные срабатывания на далёких парах | сюит, проверка (c) — коридор |
| переводные близнецы | провал на языке-двойнике | в синтетике ds1000 есть, **в сюите нет** — хвост |
| type/lang рассогласования | неверный вес `type_match`/`lang_match` | фичи есть, **проб нет** — хвост |
| дегенераты | пустые/вырожденные записи | **не покрыто** — хвост |

Правила пополнения:

- **«Одна фича вошла — один класс проб вошёл»**, в том же PR: новая фича
  в `FEATURE_NAMES` обязана прийти с пробами своего класса (иначе сюит
  структурно слеп именно там, где модель изменилась).
- **Негативный фикстчер обязателен:** сломанный бандл (переставленный
  порядок фич-колонок) ОБЯЗАН фейлить сюйт — регрессионный тест
  `tests/test_eval_sanity.py` держит инверсию #480 воспроизводимой до знака.

## 8. ADOPT-отчёт: форма

Каждый ADOPT-отчёт **открывается таблицей покрытия поверхности**
(класс проб → пробы → источник; §7) — читатель сначала видит, что именно
умеет видеть методология, и только потом цифры. Числа без таблицы покрытия
не цитируются (правило с 2026-10-03, урок #480).
