## 1. Null-покрытие (мажоритарная позиция DE+ML; диссент NA записан)

- **Доля:** created_at=None у ≈ 1/3 кластеров, РАВНОМЕРНО по ВСЕМ стратам
  (CH-3, CH-0/CH-5, CH-2, CH-4, все три субстрата theme-near
  пропорционально) — факторное покрытие оси конверта, не диагональное.
  **Диссент NA** («null только в негативном блоке как осознанный
  консервативный предел») отклонён большинством: он ломает
  ратифицированную пробу 7 санити §6.1 (null-self-кластер обязан быть
  fold-eligible, урок v42 double-null) и создаёт прокси «null → abstain».
- **Только both-null пары:** смешанные null/non-null запрещены
  (fail-closed ассерт «0 mixed-null»; mixed вне объёма v1).
- Существующие строки байт-идентичны (расширение, не ре-эмит;
  id-стабильность листа); таблица квот пере-ратифицируется с
  null-добавками формулой от объёма страты.

## 2. Ассерты (fail-closed)

| # | Ассерт | Правило |
|---|---|---|
| A-null-indep | P(None\|страта) = 1/3 ± 0.05 на каждой страте; null независим от метки и ориентации (компаньоны A-created-indep, A-symmetry) | I(null-флаг; label) ≈ 0 — фича не несёт сигнала класса |
| A-null-lang | доли null равны по трём субстратам | запрет стека прокси «язык+null» |
| A-null-cover | ≥ 20 null-представителей на каждый субстрат | в-манifoldость envelope-блока |
| A-null-pin-строгий | каждая null-строка соответствует A-null-pin (double-null семантика, epoch+флаг) | как в манифесте сборки |
| 0 mixed-null | пар с одним null-конвертом не существует | следующий вне-манifold не создаётся |
| дизъюнктности | хэш-ноги против noharm-поверхности `146a8ae4…` / train / holdout id-манифеста / sheet member_ids | из ADDENDUM-3 §2 сохраняются |

## 3. Порядок (ADDENDUM-3 §3 целиком, без сокращений)

Генерация null-добавок (свежие seeds, пины до генерации) → ассерты §2 →
retrain → re-CV τ_hi/τ_m (per-substratum abstain ≥ 0.9 сохраняется;
CV-noregress допуск фиксируется до ретрейна) → новый frozen-артефакт →
ВСЕ флоры заново (floor_q → q; floor_seed по ратифицированной процедуре
ADDENDUM-2 с новым sha → δ_acc; floor_inv; floor_perm) → санити 7/7 →
noharm QA (ожидание 0/171 + 0/27) → пре-launch чеклист → single-shot.

**Терминальность:** noharm ≠ 0/171 после итерации 3 → итерация 4 запрещена
без НОВОГО верифицированного корня + санкции MLC; развилка — ArchCom или
честный DECLINE линии v1.

## 4. δ_acc: буква неизменна; пред-регистрация до чтения

- **Арифметика верифицирована председателем лично** (вызов ML-инженера
  рассмотрен): floor-seed таблица iter-2 — дельты 0.24–0.48 (seeds 43–52),
  max pairwise |Δdelta| = 0.24 → δ_acc = max(2·0.24; 0.10) = **0.48**.
  Двойного множителя нет: 0.36–0.48 из отчёта — другой набор розыгрышей
  (QA-диагностика), не floor-seed. Процедура ADDENDUM-2 применяется к
  новому sha без изменений.
- **Буква не правится** (3/3): правка порога после неудобных чисел
  неотличима от подгонки (класс #480 с другой стороны); определение §4
  включало модельную ногу с самого начала; двойного счёта нет — пол это
  допуск, падение дельты это размер эффекта.
- **Пред-регистрация (пишется в run-log ДО gate_start, дословно):**
  «ратифицированная процедура на материал-чувствительной модели даёт
  δ_acc = 0.48; свежие дельты 0.24–0.48 (медиана 0.44). Если g_acc красный:
  интерпретация — "модель v1 не сертифицируемо превосходит базлайны под
  собственной ратифицированной процедурой допуска"; вердикт цикла DECLINE
  окончателен, повтор с теми же числами запрещён, возврат только через
  новый fresh-seal цикл с канон-вопросом о семантике пола в ArchCom.
  Послемёрная аналитика (легальна): дельта holdout сравнивается с
  распределением 10 розыгрышей — внутри диапазона → "нестабильность на
  свежем материале" (дефект покрытия/рецепта), ниже хвоста → "реальная
  слабость на holdout"; оба исхода = DECLINE, порог не пересматривается».
- После итерации 3 δ_acc пересчитывается механически по букве ДО чтения
  (если пол снизится — снизится до чисел); после sealed-чтения перемер
  пола цикла запрещён.

## 5. Отвергнутые альтернативы

- Null только в негативах (NA): ломает пробу 7 санити + прокси «null →
  abstain» (мажоритарное отклонение, диссент записан).
- Null только на кросс-языке: стек прокси «язык+null» (урок итерации 2).
- Правка буквы δ_acc / робастная статистика пола: outcome-aware правка.
- Итерация 4 без нового корня: бесконечный пре-лаунч чурнинг.
