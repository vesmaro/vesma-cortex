## 0. Линия наследования

- round-4 F-лег: REJECT (g1 0.9406 PASS / g2 <0.96 FAIL / g3 MRL FAIL / g6a
  16.5ms PASS); прод не тронут — round-3 `3b752e06`.
- Диагностика post-factum: рецептура RU↔EN подняла translated-dup косинусы
  (+0.069 медианы на сожжённых 144 парах), IMPROVED not CURED; осознан gate-gap
  (гейты round-4 не меряли кросс-языковость).
- Корень (верифицирован по model-report): поточечная KD не видит ПАРУ; студент
  упирается в геометрию учителя на переводах.
- Пере-скоуп 09.10: characterization на незагрязнённом гейт-наборе показала, что
  априорные пороги нефальсифицируемы; гейты переведены на поклассовые
  косинусные контуры по слабым стратам (см. §4).

## 1. Целевая функция и конфигурация (плечо A — база)

1. Посрезовая KD (без изменений: MSE на cos к вектору учителя, срезы
   64/128/256/384, L2-ренормализация каждого) **+ translation-контрастивный
   член** на переводных парах корпуса (позитив = пара, негативы — in-batch;
   при CPU-батчах <32 — парная cos-функция; финальная механика по пилот-сетке).
2. Пилот-сетка λ/температуры на 25% корпуса (~45 мин), выбор фиксируется в
   run-log ДО полного прогона.
3. `--mrl-weights 4,2,1,1` — в базовом конфиге (страховка срезов под
   мониторингом g3).
4. 16–20 эпох; ранняя остановка: val R@5 улучшается <0.001 четыре оценки
   подряд (правило зафиксировано до старта).
5. Селекция чекпоинта — ТОЛЬКО по val-срезу, критерий min-over-slices R@5
   (slice-aware), + мониторинг seed-dup/llm косинусов по эпохам (training-loop
   правило: см. §4.3). Judged-корпус не читается до селекции и экспорта.

## 2. Плечи (все прег-регистрированы; вектора разных KD-учителей не
переиспользуются; гейт-набор не пере-переводится)

| Плечо | Состав | Условие | Цена |
|---|---|---|---|
| A (база) | контрастив на существующих 4038 парах, учитель 0.6B | всегда | ~9–10 ч |
| Учитель | тот же лосс на векторах аудированного KD-учителя (e5-base/LaBSE/MiniLM; аудит: медиана ≥0.90 на 144 сожжённых парах + одноязычный зонд \|Δ|≤0.005) | аудит PASS | +~6 ч |
| B (корпус) | тот же лосс на пере-переведённом корпусе (все 4038 строк, 50-парная round-trip chrF проба учителя) | DE-lane готова | +2–6 ч |
| A/45M | identity-init ReZero 45M | триггеры: train-loss падает, гейты стоят; g2-gap ≤0.01 | +5.1 ч |

Если успело только B без A — один прогон B с честной пометкой «вклад данных не
изолирован».

## 3. Корпус round-5

- База: sealed round-4 corpus fp `7a3bf00b…` (train 24221 / val 1275) МИНУС
  исключения гейт-набора: 315 строк (file:line:source) / 360 text SHA
  (manifest `r5_gate/manifest.json`, гейт-набор SHA `cb367577…`).
- Плюс Tatoeba-страт: 1500 строк / 750 псевдо-заметок (SHA `0be59a69…`,
  CC-BY 2.0 FR, атрибуция и авторы в манифесте; деконтаминация 0 попаданий).
- Asserts сборки: **hash-уровень** — дизъюнктность pair_id / text-SHA против
  гейт-набора и сожжённых пар (ни одна исключённая строка не осталась);
  **n-граммы 8–13 zero-tolerance — ТОЛЬКО для нового материала (Tatoeba)**;
  направления; НОВЫЙ corpus fingerprint + double-run детерминизм;
  используется ТОЛЬКО завершённый ассерт-набор (`feat/embed-r5-corpus` @
  `0faaf9b`+).
- **Коррекция скоупа 09.10 (до прогона)**: исходная формулировка «n-граммы
  8–13 против гейт-набора и сожжённых пар по всему корпусу» неисполнима by
  construction — гейт-набор нарезан из translated-семейства того же sealed
  корпуса; same-document соседи гейт-текстов (186 строк = 0.74%, из них 73 —
  другие записи тех же store-документов) — легитимный тренировочный материал;
  утечки измеряемой пары нет — обе стороны гейта исключены по hash (assert
  PASS). Унаследованная база = hash-уровень (семантика ратифицированной
  механики `0faaf9b`); n-граммовый zero-tolerance — на новый материал.
  Популяция не меняется: train 25420 / val 1261 / total 26681;
  translated-family 0.1427 (0.1989 с Tatoeba) — под потолком 0.30; ru 0.4244.
- Свободная LLM freeform полка — отсутствует (урок коллапса round-4).

## 4. Гейты (ратифицированы владельцем 09.10; population = запечатанный гейт-набор `cb367577…`, 180 пар, один харнес — NanoProvider-рецепт диагностики, один проход)

### 4.1 BINDING ADOPT (все обязательны)

- **g1** — S1m no-harm recall@5 ≥ **0.9252** (single-shot на judged
  `c2ce056d…`, 191 запрос, production S1m механика, self-comparison only).
- **gX0** — |Δ| медианы одноязычного контроля против прода ≤ **0.005**.
- **seed-dup** (n=22, note-shaped) — медиана cos ≥ **0.85** ∧ доля пар
  cos ≥0.85 ≥ **0.50**. Полы floor-модели (REJECT-кандидат `f70672aa`):
  0.8201 / 0.2727.
- **llm** (n=68) — медиана cos ≥ **0.93** ∧ доля пар cos ≥0.85 ≥ **0.90**.
  Полы: 0.9051 / 0.7941.
- **g6a** — латентность mean ≤ **45 ms** (метод аддендум-6 §A.2; для 45M-плеча
  — перемер) ; **g7** — ≤ **60 MB**.

### 4.2 MONITORED (записанные полы кандидата; не решают ADOPT)

- real/twin поклассовые косинусы (полы 0.9344/0.9673 и 0.8621/0.9357);
- retrieval total (пол 0.9556; en 0.9444 / ru 0.9667) и поклассово;
- sibling-страта — негатив-якорь (прод медиана 0.6889);
- g2 — значение фиксируется для тренда/атрибуции (лифт-функция передана
  поклассовым гейтам);
- g3 — посрезовой замер остаётся в проходе (бесплатно), решающий вес снят
  владельцем 08.10 (потребляющей поверхности срезов нет; round-6 срез-пакет
  отменён).

### 4.3 Training-loop правило (расход CPU, не ADOPT)

- Ранняя остановка (см. §1.4);
- включение плеча A/45M — по триггерам §2;
- прокси-тренд seed-dup/llm медиан по эпохам — для мониторинга прогресса.

## 5. Измерение и дисциплина

- Гейты ADOPT — **ровно один проход** на выбранном чекпоинте (single-shot);
  характеризационные прогоны на floor-моделях (прод, `f70672aa`) — не
  гейтующие, зарегистрированы как калибровка.
- Пороги не двигаются после ратификации; любой пересмотр = новый документ +
  ратификация, никогда по итогам прогона.
- Cortex sealed holdouts/evalsets для селекции запрещены; holdout-наборы
  читает только раннер.
- Исходы: **ADOPT** — экспорт → cortex-recalib (новая сборка = новый holdout) →
  embed-release-parity; **REJECT (data-limited)** — lane закрывается
  финальным вердиктом «двуязычная глухота — известное ограничение», round-6 с
  теми же рычагами не запускается.
- Исполнение ML-ONLY (`gcw-ml-*`); TL = координация + верификация чисел его
  функцией на его данных; прод не трогается; секреты в host `~/.secrets/`.
