## 0. Мотивация (измеренные факты)

- Round-7 опроверг рычаг «качество llm-переводов» (1.7B-пары НЕ подняли llm:
  0.8920 против round-6 0.8947). llm-потолок 0.86–0.90 держится во всех
  режимах при KD-учителе Qwen3-Embedding-0.6B — чья собственная кросс-языковая
  геометрия ограничена (burned 0.7448, гейт S_cal 0.6889).
- Sweep показал: свежие базы (harrier-oss-0.6b, EGemma-2) имеют НАТИВНУЮ
  кросс-языковую геометрию уже на уровне «вылеченной» (harrier: burned 0.9407,
  S_cal 0.9889, R@5 1.0) — без всякого контрастива.
- Вывод: оставшаяся переменная первого порядка — **источник кросс-языковой
  геометрии**. Round-8 меняет её: дообучение сильной базы на нашем корпусе
  (калибровка домена + mono), затем дистилляция в 30M студента.

## 1. Двухстадийный пайплайн

**Стадия 1 — FT база:** дообучение harrier-oss-v1-0.6b (MIT) на sealed
корпусе round-7 fp `ad3d438f…` — лёгкий FT (2–4 эпохи, консервативный lr,
LoRA или полный — на усмотрение исполнителя; mono-guard-оценка каждую эпоху:
mono_control_median ≥ 0.8932 НЕ требуется для БАЗЫ — база калибруется, её
mono-margin исходно отличается от прода; вместо этого фиксируется тренд и
финальные значения для студента-этапа).

**Стадия 2 — дистилляция студента:** вектора FT-базы = учитель для
30M-студента (посрезовая KD БЕЗ контрастива — кросс-языковая геометрия уже в
учителе; контрастив в round-8 НЕ используется — одна переменная раунда).
Расписание студента: round-6 фазы (KD-only 8 эпох кап → KD-replay ≤20;
контрастив исключён), mrl-weights 4,2,1,1, slice-aware селекция.

Экспорт: dynamic int8 (round-5/6/7 рецепт).

## 2. Гейты студента (single-shot, финальный артефакт)

**Binding:** g1 ≥0.9252 ∧ gX0 |Δ|mono ≤0.005 vs прод ∧ seed-dup мед ≥0.85 ∧
доля ≥0.50 ∧ llm мед ≥ **0.90** ∧ llm доля ≥0.85 ≥ **0.75** ∧ g6a ≤45ms ∧
g7 ≤60MB.

**Рекалибровка llm-порога (rationale для владельца):** старый порог 0.93/0.90
превышал собственное измеренное значение ПРОДА на llm-классе (медиана 0.872,
доля ≥0.85 = 0.647 — sweep D3) — порог был откалиброван выше достижимого даже
действующей моделью. Новые пороги = prod-якорь + честная маржа: 0.872+0.028 →
0.90; 0.647+0.10 → 0.75. Это НЕ ослабление под результат round-7 (который дал
0.892/0.809 — всё ещё ниже новых порогов: round-8 обязан их превзойти).

**Monitored:** без изменений + recorded: FT-стадия тренды, harrier-geometría
до/после FT.
