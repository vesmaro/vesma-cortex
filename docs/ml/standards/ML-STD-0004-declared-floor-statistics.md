# ML-STD-0004 — Объявленный пол (declared floor statistics)

**Дата:** 2026-10-30 (формула ратифицирована MLC раундом 6, до розыгрышей) · 2026-10-30 (авторство)
**Статус:** `draft → approved (MLC, 2026-10-30, раунд 6, 3/3 «легальна с условиями») → ratified (владелец, дата — pending)`
**Надзирающий домен:** обучение/оценка/tooling (член комитета — gcw-ml-engineer)
**Протокол:** ратифицированная запись раунда 6 — `docs/specs/merge-arbiter-corpus-prereg-ADDENDUM-6.md` §4–§5 (письменный раунд MLC 30.10; 3/3 «легальна с условиями»; независимый перемер DE; коммит `f2b51bd`)

## 1. Что стандартизируется

Стандарт регламентирует **объявленный пол** гейтов класса floor_seed — допуск δ_acc
(и будущие допуски того же класса), который легален тогда и только тогда, когда он
выведен **ранее зафиксированной формулой** из **опубликованного до gate_start
распределения** розыгрышей состава. Порядок двухступенчатый и строго направленный:
ступень 1 — формула вывода допуска фиксируется в стандарте ДО розыгрышей; ступень 2 —
≥ 10 розыгрышей, распределение (медиана, p5, p95, max-pairwise) публикуется в run-log
до gate_start, δ_acc = формула(объявленная статистика) и замораживается до чтения.

Ратифицированная формула настоящего созыва (ступень 1 исполнена — формула стоит в
тексте стандарта до первых розыгрышей ступени 2; решение председателя раунда 6 —
момент «формулы до чисел»):

**δ_acc = max(p95 − p5; 0.10)** — допуск равен ширине объявленной полосы шума
состава; минимум 0.10 сохраняется (ратифицированный конверт модельной стороны,
ADDENDUM-2 §1: training-seed шум не измеряется — модель тренируется один раз).

Стандарт связывает авторов прегов и гейт-машин всех ML-линий vesma-cortex, имеющих
floor_seed-гейты: **все будущие преги серии merge-arbiter и другие ML-линии проекта
с floor_seed-гейтами**. Стандарт **связывает только будущие применения**: цикл v1
merge-arbiter добирает по букве 0.48 с пред-регистрацией ADDENDUM-4 §4 — задним
числом не легализуется, не пересматривается и не перемеряется (П5, П6).

## 3. Термины и легенда

- **Объявленный пол** — допуск гейта (δ_acc), вычисленный зафиксированной до розыгрышей
  формулой из опубликованного до gate_start распределения розыгрышей состава. Пол —
  свойство рецепта и состава (наследует ML-STD-0001: «пол — свойство рецепта и ступени,
  не пожелание автора»); пол, вычисленный после увиденных чисел из хвоста самого
  улучшения, объявленным не является.
- **Полоса шума состава** — интервал [p5, p95] распределения гейтующей статистики по
  розыгрышам; ширина p95 − p5 — измеренный вклад жребия состава при неизменном здоровье
  модели. Формула 0004 делает допуск равным этой ширине (с минимумом 0.10).
- **Ступень 1** — фиксация формулы вывода допуска в стандарте ДО розыгрышей («формула
  до чисел», решение председателя MLC раунда 6). Исполнена настоящим созывом: формула
  стоит в §1/П2 до первых розыгрышей.
- **Ступень 2** — исполнение розыгрышей (≥ 10), публикация распределения в run-log до
  gate_start, вычисление δ_acc по формуле ступени 1 и заморозка до чтения.
- **Розыгрыш состава** — независимая композиция материала (наследует ML-STD-0001;
  операционально — процедура ADDENDUM-2 §2: seeds пинены списком, гейтующий агрегат
  из свежего синтетического материала тем же кодовым путём, дизъюнктность fail-closed
  против train/holdout).
- **Распределение розыгрышей** — публикуемый набор статистик: медиана, p5, p95,
  max-pairwise. Все четыре обязательны; в формулу допуска входит только пара p5/p95.
- **max-pairwise** — максимум попарных |разностей| статистики между розыгрышами;
  характеристика экстремального хвоста. В формулу допуска не входит — вход хвоста
  эффекта в допуск и есть болезнь v1 (§4).
- **δ_acc** — допуск гейта g_acc: минимальная дельта превосходства модели над лучшим
  базлайном, при которой превосходство считается сертифицируемым.
  δ_acc = max(p95 − p5; 0.10); минимум 0.10 — ратифицированный конверт модельной
  стороны (ADDENDUM-2 §1: training-seed шум не измеряется — модель тренируется один раз).
- **Процессный инцидент** — нарушение дисциплины объявленного пола: исполнение гейта
  с допуском, расходящимся с объявленным; смена формулы/надбавки после увиденных чисел.
  Не гейт-исход: эскалация MLC/владельцу; вердикты цикла под инцидентом недействительны.
- **Класс #480** — outcome-aware правка порога/формулы/надбавки после увиденных чисел
  (по имени прецедента «правка под результат»); смена формулы после чисел = этот класс
  независимо от направления правки.
- **Послемёрная аналитика** — легальный анализ в отчёте: дельта holdout сравнивается
  с распределением розыгрышей; внутри диапазона → «нестабильность на свежем материале»,
  ниже хвоста → «реальная слабость на holdout». Аналитика не меняет вердикт и не
  пересматривает порог (ADDENDUM-4 §4); это аналитика, не перегородка.
- **Sealed-чтение / single-shot** — чтение запечатанных поверхностей один раз; после
  события single-shot перемер пола цикла запрещён (П6).
- **floor_q / floor_inv / floor_perm** — полы родственных гейтов линии (q, инвариантность,
  перестановочная проба); их распределения публикуются в тот же раздел run-log (П4),
  пороги гейтов каноном не трогаются.
- **†** — пометка уточнения сверх дословного текста ратификации, внесённого при
  авторстве; полный перечень — в сопроводительном отчёте авторства (30.10).

## 4. Альтернативы отвергнуты

1. **Якорь медианы улучшения (DE, раунд 6):** δ_acc = медиана + (p95 − медиана),
   то есть p95 дельт улучшения. Отвергнуто: делает допуск квантилем самого улучшения —
   пол измеряет не шум состава, а размер эффекта; воссоздаёт недостижимость v1
   (допуск 0.48 при медиане дельт 0.44 и потолке дельты ≈ 0.48 — гейт красит любую
   модель). Позиция DE «любой двойной множитель требует отдельного обоснования»
   сохранена (ADDENDUM-6 §4).
2. **Пост-фактум max-pairwise×2 (болезнь v1):** δ_acc = max(2·max-pairwise; 0.10) по
   фактически наблюдённому хвосту дельт улучшения. Отвергнуто для будущих прегов:
   множитель от экстремального хвоста распределения эффекта гарантировал DECLINE при
   потолке ≈ 0.48 (ADDENDUM-4 §4: max pairwise 0.24 → δ_acc 0.48 при медиане 0.44) —
   допуск строился из собственной недостижимости. С этого стандарта max-pairwise
   публикуется как характеристика хвоста, в формулу не входит; v1 добирает по букве
   0.48 (не-ретроактивность, П5).
3. **Плоский 0.10 без замера.** Отвергнуто (остаётся в силе с ADDENDUM-2 §4): ассерт
   вместо измерения против ML-STD-0001; 0.10 — вероятный недомер в небезопасную
   сторону. Формула 0004 сохраняет 0.10 только как нижний конверт ПОВЕРХ замера полосы,
   не как замену замера.
4. **Ретроактивное применение 0004 к v1.** Отвергнуто (ADDENDUM-6 §5): буква 0.48
   стоит; правка допуска после неудобных чисел неотличима от подгонки (класс #480
   с другой стороны); послемёрная аналитика легальна, перегородкой не является.
