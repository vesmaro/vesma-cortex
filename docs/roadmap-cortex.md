# Дорожная карта vesma-cortex — связка «эмбеддер + граф-кортекс»

> Создана 22.10 (директива владельца: цель, сроки, актуализация с
> корректировкой, связь с релизными поездами vesma). **Живой документ**:
> дельта — в каждом отчёте волны; смена ветки ADOPT/REJECT = немедленная
> актуализация дат и уведомление владельца.

## Цель — что такое «эффективная рабочая связка»

Прод-эмбеддер round-3 (`3b752e06`, действует) + кортекс-модель **ревизия
1.n с 5 граф-фичами** в проде vesma: движок решает «дубликат / не
дубликат» с учётом связей памяти (рёбра графа), без деградации текущего
качества (no-harm). Эмбеддерная линия замен закрыта (REJECT финален
22.10) — связка строится на действующем эмбеддере; замену эмбеддера можно
открыть только новым прегом владельца.

> **Позиция ратификации №5 (пакет M1.1, PA):** переформулировка цели —
> «dup-вердикт, в котором связи памяти защищают от ложного схлопывания;
> детекция пере-сохранений — за классификатором без граф-претензий;
> схлопывание — за консолидацией движка». До ратификации читается
> формулировка выше.

## Риск-ветки (что сдвигает даты)

- **g4 FAIL** — разрешён АрхКомом 22.10: g4-as-designed закрыт как
  неприменимый (популяция пуста по построению — перепись DE); вопрос
  «помогают ли графы в dup-детекции» не опровергнут, а ПРИЗНАН НЕТЕСТИРУЕМЫМ
  при текущей семантике минта; reopen — дрейф-монитор (≥30 dup-пар с
  ненулевым граф-вектором: правки тел / кросс-языковой минт / движковое
  сшивание D). В 1.n+1 аттрибуция графа — только неблокирующая
  характеризация специфичности (A2.8).
- **g2/g3 FAIL**: разбор корпуса-дефекта по прецеденту b2p-v41 (лечилось
  корпусом, не сьютом) ≈ +2-4 дня.
- Живой стор растёт ~50 записей/день — пул стареет медленно; свежий зонд
  перед M3 бесплатен.

## Связка с релизными поездами vesma

Модель едет в бандле (VesmaProvider pin) **очередного релиза vesma после
M3**. Кандидат на поезд = ближайший движковый поезд после готовности
интеграции. Критерии: модель готова = M2 ADOPT; интеграция готова =
sanity-CI зелёный на бандле; релиз = коммиты + тег + release-объект
(канон «релиза» владельца 06.10). Движковый поезд M2 не ждёт и не
блокируется.

## Параллельные линии (вне этого цикла)

- **B0**: instrument-and-defer (владелец 19.10) — ~4 недели
  инструментированных данных → решение по числам.
- **Embed-линия**: закрыта финально; reopen = новый прег владельца
  (прецедент 20.10).
- **Watchlist граф-блока** (при REJECT): триггер пересмотра = доля
  эвиденс-записей в проде (пересчёт зондом).
