# Чартер vesmaro-cortex — локальная модель решений для экосистемы памяти

- **Статус:** Accepted (чартер волны A0; утверждён Tech Lead 2026-09-29, выделение
  из волны 5 vesmaro-canon по решению владельца)
- **Дата:** 2026-09-29
- **Владелец репозитория:** owner (vesmaro); исполнительная роль — Tech Lead

## 1. Что мы строим

**Одна модель — одна задача.** Локальная модель решений **mnema-роутер**
(марка моделей `mnema-*` не меняется вместе с именем репы): принимает пару
записей памяти (canon-state, конверт + тело, собранный под запрос по правилу 2
[ADR 0004](https://github.com/vesmaro/vesmaro-canon) движка vesmaro) →
**типизированный вердикт `is-duplicate(a, b)` + скор уверенности [0, 1]**.
Выход совместим с примитивами `Noul`/`Score` интерфейса decision-провайдера
(ADR 0004 канона); продуктовая роль — «советчик дедупликации» (guard-подсказка),
не автономное слияние.

**Архитектура с нуля.** Специализированная узкая архитектура «как Jev, но своя»:
не языковая модель, не SFT готовой LLM — решение владельца 2026-09-29.
Кандидаты разбирает АрхКом (A1): twin/Siamese-энкодер над парой;
cross-encoder; маленький transformer, обученный с нуля; НЕ-нейросетевой
контроль (градиентный бустинг над фичами пары) — обязательный внутренний
baseline-кандидат.

**Где живёт.** Инференс — ноль сети, веса на машине владельца (surface (b)
ADR 0004 + аддендум W5a). Обучение — XPU (Intel Arc 140T, nano-llm контейнер,
руки владельца) + self-supervised pretraining на неразмеченных парах стора.
Подключение в движок — `MnemaProvider`, волна W5d в vesmaro-canon.

## 2. Что мы НЕ строим

- **Не LLM и не SFT:** модель не генерирует текст вообще; тела записей пишут
  люди и агенты (стилевой канон §4 канона), провайдер не переписывает контент.
- **Не внешний сервис:** ни одного исходящего вызова на инференсе; внешний
  Jev-адаптер — отдельная поверхность (c) ADR 0004, к этой репе отношения
  не имеет.
- **Не автономный исполнитель:** вердикт — совет; слияние записей всегда
  остаётся решением движка/владельца.
- **Не research-парк:** одна задача is-duplicate; расширение примитивов
  (`Choice`, quality-скоринг) — отдельные решения, не этот чартер.

## 3. Scope-рамка имени cortex

Имя `vesmaro-cortex` — эволюционное: «кора» = ассоциативные и исполнительные
функции над памятью, а не хранение. Стартовое содержимое репы — обучение модели
решений (mnema-роутер). Имя допускает будущее расширение до «дома локальных
когнитивных сервисов памяти» (curator, gc-подсказки и т.п.), **но любые новые
скоупы — только через отдельное решение владельца**; скоуп-крип под влиянием
имени запрещён. Правила именования экосистемы фиксирует АрхКом A1 (ADR в этой
репе).

## 4. Контракты, которые связывают репу

| Контракт | Чем связывает |
|---|---|
| [Препрег v2](https://github.com/vesmaro/vesmaro-canon) (canon, заморожен до прогона) | оценка модели — ТОЛЬКО по нему: 7 стратов / 200 пар, holdout 30 % single-shot, 6 метрик, baseline = косинус 0.92 |
| [ADR 0004](https://github.com/vesmaro/vesmaro-canon) + аддендум W5a | интерфейс провайдера (`Choice`/`Score`/`Noul`), surface (b): ноль сети, секрет-скан = гигиена экспорта, правило 4 без льготы за локальность |
| Отчёт W4c + Jev-разбор (canon) | почему внешний суррогат отклонён (3/17, Brier 0.70) и что такое Jev как класс |
| Дисциплина фингерпринтов (ADR-0021 движка) | fingerprint весов = событие перекалибровки; та же дисциплина, что у эмбеддера |

Размеченный корпус 200 пар строит канон-сессия (W5b) по замороженной процедуре
— это контракт калибровки, не собственность этой репы. Pretrain-корпус из
неразмеченных пар стора строится здесь (A2) по той же гигиене: секрет-скан +
`no-federate` ДО экспорта, read-only URI, в репу — ни одной сырой строки.
Расширение train-определения сверх «≈140 пар» = аддендум препрега, пуш в canon
main ДО любого прогона оценки.

## 5. Критерии успеха

1. **Продуктовый бар — ADOPT по препрегу v2:** все 6 условий одновременно на
   holdout (типизированность 100 %; sensitivity ≥ 0.90; specificity ≥ 0.90;
   Brier ≤ 0.25; строго лучше baseline по balanced accuracy; record-quality
   полнота 100 %). DECLINE — нормальный честный исход (прецедент W4c);
   NO-DATA — по floor'ам препрега.
2. **Артефактный бар:** веса + fingerprint весов + спецификация инференса
   (формат входа/выхода, ADR-0004-совместимая) — достаточно, чтобы движок
   (W5d) загрузил модель локально, без сети.
3. **Воспроизводимость:** сиды, фингерпринты данных и весов, провенанс XPU-среды;
   holdout-изоляция ассертами в коде (holdout недостижим из train-петель).
4. **Гигиена:** ни одной сырой строки стора в репе; секрет-скан и `no-federate`
   до экспорта любых данных.

## 6. Нефункциональные рамки

- **Бюджет XPU:** Intel Arc 140T (fp16 ≈ 3.3 TFLOPS, память nano-llm
  контейнера); обучение — разумные часы, не дни; CPU-смоук формы пайплайна
  обязателен до любого XPU-запуска.
- **Локальность:** датасеты, обучение, инференс, оценка — на машине владельца;
  исходящего трафика нет ни на одном шаге.
- **Управляемость:** XPU-запуски — только руки владельца по ранбуку
  copy-paste; репо поставляет код + ранбук + CPU-смоук.
- **Размещение:** local git первым шагом; GitHub-размещение (приватная репа в
  орге vesmaro?) — решение владельца.
