# Синтетический корпус стадии 1 (A2s)

- **Статус:** реализовано (срез A2s, ветка `feat/a2s-synthetic`)
- **Рамка:** ADR 0001, аддендум владельца П3 (2026-09-29); контракты —
  [data-contract.md](specs/data-contract.md) §5 (фингерпринты)
- **Код:** `src/cortex/synth/generate.py` (чистый, без сети) +
  `scripts/gen_synth_corpus.py` (CLI с ollama — единственное место с HTTP)

## Что это

Модель `mnema-cortex` принимает **числовые признаки пары**, не сырой текст
(ADR 0001 V1/П3). Поэтому LLM здесь — **генератор текстовых пар с метками по
построению**, не судья и не учитель языка: пара создаётся с заданной
семантикой, метку даёт стратегия, и все пары идут через штатный
фиче-экстрактор (`cortex.features.pair.features`).

## Стратегии

| Стратегия | Метка | Механика | Зона обучения |
|---|---|---|---|
| `paraphrase` | 1 | LLM переписывает запись с сохранением смысла; сверху — процедурная бессмысленная вариация из `corruption.py` (регистр/пунктуация/порядок тегов) | слабые позитивы |
| `near-topic` | 0 | LLM пишет НОВУЮ запись на ту же тему, но с другим фактом/выводом | жёсткая зона W4c: глобально близко, локально другое |
| `broken-field` | 0 | процедурно: тот же текст, сломано одно поле (композиция над существующими hard-негативами `corruption.py`) | урок W4c |
| `trivial-negative` | 0 | процедурно: записи на разных темах | очевидные негативы |

Движок тем: 40 сид-тем memory-домена (настройки инструмента, решения,
чекпоинты, конфиги окружения, lessons learned; RU и EN пополам), список
заморожен в `TOPICS`. RU/EN-записи одной темы — переводы с общим `key`;
**переводные близнецы запрещены как негативы** (иначе — ложная метка по
построению).

Механика повторного базиса (для корпуса 1200–1600 пар каждый базис
используется 7–10 раз на стратегию): повторные промпты получают строку
«вариант №k» (при temperature 0 одинаковый промпт = одинаковый ответ),
коллизии pair_id гасятся ограниченным числом ретраев (`MAX_ATTEMPTS = 4`) и
считаются отбросами, никогда не молча.

## Команды

```bash
# 1. СЭМПЛ ДЛЯ ВЛАДЕЛЬЦА (гейт): 24 пары = 8/8/4/4, ~5–15 мин на CPU
uv run python scripts/gen_synth_corpus.py --sample 24 --out-dir data/synth-sample

# 2. ПОЛНЫЙ КОРПУС — только после валидации сэмпла владельцем
uv run python scripts/gen_synth_corpus.py --pairs-per-strategy 300   # ~1200 пар
```

Ключевые флаги: `--seed` (по умолчанию 7), `--model` (по умолчанию
`qwen2.5:7b-instruct`), `--host` (по умолчанию `http://127.0.0.1:11434`),
`--num-predict`, `--timeout`, `--force` (перезаписать существующий корпус —
по умолчанию отказ: зафингерпринченный корпус не затирается).

## Выход (data/synth*/ — gitignored, контент в репу НЕ коммитится)

- `pairs.jsonl` — по строке на пару: `pair_id`, `strategy`, `label`
  (`duplicate`/`not-duplicate`), `record`, `candidate`, `seed`;
- `manifest.txt` — строки `pair_id <sha256>`, отсортированы (схема §5
  data-contract);
- `report.json` — **корпусный фингерпринт BLAKE2b-256** от манифеста,
  счётчики стратегий и отбросов (`dropped_empty/length/identical/duplicate/
  same_topic`, `llm_calls`), баланс меток и полный провенанс: модель + digest
  из `/api/tags`, options (temperature=0, seed = master seed + номер вызова,
  num_predict), `PROMPT_VERSION`, время.

Воспроизводимость: процедурные стратегии детерминированы по сиду строго;
LLM-часть пиннится temperature=0 + per-call seed — повторяемо на той же
машине/модели, контроль — совпадение фингерпринта при перегенерации.

## Дисциплина П3

- Синтетика идёт **только в претрейн-стадию 1**; владельческие ~140 пар —
  стадия 2; оценка — только по реальному holdout препрега v2. Метки синтетики
  не расширяют train-определение препрега.
- **Триггер аддендума:** если синтетика когда-либо попадает в supervised-фит
  ИЛИ в претрейн финальной оцениваемой модели — аддендум препрега v2 пушится
  в canon main ДО любого прогона оценки (ADR 0001 П3; формат — после
  A3b-экспериментов, когда измерен вклад синтетики). До тех пор — не нужен.
- LLM-судейство допустимо только как валидация выборки; финальная валидация —
  кодбук: сэмпл 20–30 пар глазами владельца до использования корпуса (этап 1
  выше, `--sample 24`).
- Одна задача — один корпус (только is-duplicate); носители — без
  параллельных агентов (OOM-дисциплина), генерация последовательная.
- Секретов синтетика не несёт (темы — заготовки, не стор), но контент в репу
  всё равно не коммитится: только фингерпринты, счётчики, код.

## Тесты

`tests/test_synth_corpus.py` — метки по построению, отбраковка кривого вывода
LLM со счётчиками, сид-детерминизм, переводные близнецы, масштаб (quota 40 >
пула без крашей), вариант/ретрай-механика, совместимость с фиче-путём,
фингерпринт-схема, поверхность CLI. AST-тест запрета сетевых импортов в
`src/cortex/**` остаётся зелёным — HTTP живёт только в скрипте.
