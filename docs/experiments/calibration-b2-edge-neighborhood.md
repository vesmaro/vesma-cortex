## Обязательный adversarial sanity suite (поправка протокола, 2026-10-03)

> **Почему:** «B2 scored sens 0.989 while inverting the self-pair — the
> eval surface had no exact self-pairs» (vesmaro/vesma#480).

Каждый ADOPT-вердикт отныне обязан пройти adversarial sanity suite — ДО
цитирования любых других метрик. Четыре проверки на синтетических пробных
записях против артефакта-бандла (ONNX + манифест):

| # | Проверка | Требование |
|---|---|---|
| a | self-pair: запись против самой себя, cos = 1.0 | P(dup) ≥ 0.9 |
| b | near-boundary: лёгкая пертурбация записи, cos ≈ 0.99 | P(dup) ≥ 0.5 (cut) |
| c | unrelated: разные темы, cos = 0.578 | P(dup) < 0.5 |
| d | monotonicity: фиксированная пара, P не растёт при падении cos по лестнице {1.0, 0.99, 0.95, 0.8, 0.5} | нестрогое невозрастание |

Дополнительно suite проверяет контракт бандла до семантики: sha256
модели == манифесту; порядок фич в манифесте и в ONNX-метаданных ==
замороженному 13-фиче-контракту (`cortex.features.pair.FEATURE_NAMES`);
`feature_set_sha256` == дайджесту этого порядка; candidate == d-boost.

Исполнитель: `uv run python scripts/eval_sanity_suite.py --bundle
<dir-или-model.onnx>` (машинный отчёт — `--json`; exit ≠ 0 = провал,
ADOPT невозможен). Регрессионные тесты — `tests/test_eval_sanity.py`
(здоровый бандл зелёный; колоночно-рассинхроненный — пойман на self-pair).
Self-pair-проверка контент-независима по построению (все фичи записи
против самой себя вырождаются в константу), поэтому её число одинаково
у любого исполнителя — провал #480 воспроизводится до знака.

## Постскриптум (2026-10-03, post-merge)

Независимый post-merge замер через provider wrapper на реальных записях
стора инвертировал self-пару: **P(dup | запись против самой себя) =
0.0108** (должно быть ~1.0; W5d-артефакт на той же паре давал 0.80) —
vesmaro/vesma#480, поймано preflight-цепочкой релиза 5.4.0. Adversarial
sanity suite (см. выше) воспроизводит инверсию независимо: 0.0108 на
self-pair и 0.0052 на unrelated-пробе (cos 0.578) — совпадение с
замером #480 в пределах float32. Числа ADOPT выше остаются валидными
ДЛЯ ИХ ПОВЕРХНОСТИ ОЦЕНКИ: в dataset-v3 holdout не было ни одной точной
self-пары (и модель на этой поверхности действительно сильна). Артефакт
под расследованием — главная версия: desync порядка фиче-колонок
экспорта против замороженного 13-фиче-контракта, который манифест
заявляет. Флаг `decision_provider` остаётся заблокированным
(`deterministic`) до разрешения; отзыв/перекалибровка артефакта —
решение cortex-track TL/владельца.
