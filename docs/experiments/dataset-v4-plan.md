# План dataset-v4 / перекалибровка B2' — сводный бриф (2026-10-04)

**Статус:** план готов; ждёт (а) ратификации владельцем labeling-политики
T0–T3, (б) B0-вердикта 16.10 для старта retrain. Сборка корпуса стартует
сразу после (а).

## 1. Три источника требований (консолидированы)

**A. Расследование P0** (`p0-export-desync-investigation.md` §8.1 —
корневая гигиена угла):
- клоны-негативы: запрет с 0-толерантностью (в ds1000/v3 их 26–29);
- exact-угол: квота ≥10 DUP-строк (в v3: 15 dup vs 35 not-dup);
- type/lang: квоты вариативности (в B1 `record_type=None` во всех строках,
  `lang_match` — константа, `tag_jaccard` — 0 % важности: фичи инертны);
- cos-стратификация вниз до 0.4–0.5;
- гейт приёмки корпуса: после обучения отчёт важностей — «ни одна
  контрактная фича не константа/ноль» (corner-QA счётчики в
  `build_train_manifest.py`/`verify_dataset.py` ДО обучения).

**B. Labeling-политика T0–T3** (`docs/specs/labeling-policy-b2.md`,
proposal — ждёт ратификации): семантика дубликата («та же мысль и те же
факты другими словами = дубликат; изменился хотя бы один факт = НЕ
дубликат; только метаданные = НЕ дубликат; контент-эквивалент = дубликат;
спорное → not-duplicate»), асимметрия цены ошибок по коду движка
(zero-loss канон), corner-гейт валидатора, rulebook синтеза.

**C. Находки Layer A v2** (`artifacts/manifests/layer-a-evalsets.md`,
LA-2): прод-B1 слеп к переводным близнецам (sens 0.00, 0/12) и почти слеп
к пересказам (sens 0.17, 2/12) → корпус ОБЯЗАН включать двуязычные
дубликаты и пересказы-позитивы; hard-negatives (near-topic) сохраняются.

## 3. Критерии успеха (фиксируются в прereg ДО прогона)

1. Sanity: self_pair ≥ 0.9, монотонность, near/unrelated — PASS.
2. Layer A v2: инварианты PASS; коридоры в пределах max(0.02; CI95) к B1.
3. Целевые (коридор-класс, не гейт): translation-twins sens ≥ 0.5;
   paraphrase sens ≥ 0.5; контрактные фичи type/lang/tag живы (важность > 0).
4. ADOPT по препрегу v2 (sens/spec ≥ 0.90, Brier ≤ 0.25, строго лучше
   baseline по BA).
5. Прод-переход: только после B0-вердикта + ратифицированного отчёта;
   откат — одной строкой по ранбуку.
