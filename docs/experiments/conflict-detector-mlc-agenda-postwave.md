## 2. Ратификация фактом — банд-доли razor

Плановая доля razor-банда [0.95, 1.0] была «≥ 27 % (floor)»; замер
прибора дал **74.7 %** (razor-позитивы 191, hard window [0.7; 0.75]
пуст — закономерно: физика нано-эмбеддера не опускает same-subject
ниже ~0.66 на конвенции). Прошу MLC принять измеренное распределение
как запиненный факт манифеста (measure→fix отработал как ратифицирован:
доли зафиксированы после замера, ассерты fail-closed зелёные).
Пин: `data/conflict-detector/pin.json`.

## 3. Q1 — `in_cache_prefix` proxy (линия W0, ADR 0007)

Proxy кэш-префикса без наземной истины (сайдкар не хранит позицию блока
относительно cache-breakpoint); метод объявлен в манифесте фриза; решение
TL: proxy остаётся. Топик MLC: аддендум к ADR 0007 (декларация proxy-
статуса + что нужно для наземной истины). Материал: базовый отчёт
`window-baseline-2026-11-01.md` в wt/w0-spec, карточка w0-window-telemetry.
