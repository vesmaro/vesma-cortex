## 1. Диагноз цикла-1 (консолидация MLC-7, якорь G4 подтверждён)

- **Поверхность решения немонотонна** по числу бенигных подстановок
  (логит-качели +8.5 → −1.2 → +10.4 на razor-фикстуре, run-log v1) —
  деревья интерполируют непокрытую ячейку «конфликт + парафраз в razor».
- **brier 0.0 — сертификат насыщенности, не здоровья**: переуверенные
  p≈0/1 (маржа ~0.007 от {0,1} на всём агрегате) при нуле буфера к cut.
- **Фикстурные лестницы прошли по селекции, не по стабильности**:
  cosmetic bit-identical, para1 no-op на 2/3, nc1-single в NOT-глубине —
  лестницы не сэмплируют razor-полосу, где живёт граница (пробел
  зондирующего инструмента).
- **Носитель-асимметрия (DE, гипотеза с числами)**: para-носители в razor
  есть только у 4/11 страт (N2 у NC-2, N1 у CD-1/2/4); 7 страт с нулевым
  покрытием. Причинность не доказана (holdout запечатан) — амплификатор,
  не диагноз.
- **Калибровка исключена монотонностью**: temperature/isotonic не меняют
  сторону порога при фиксированном cut ⇒ g_stab неизменен в принципе;
  «перекалибровка с переносом cut» = HARKing на сожжённом holdout.
- **floor_inv=0 структурен** (case-only инвариантен по построению — пол
  не несёт эмпирики); никакой защитимый норматив не допускает 41.7%
  переворотов; пересмотр порога не спасает v3 и не предшествует циклу-2.
