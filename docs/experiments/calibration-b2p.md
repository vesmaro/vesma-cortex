## Постановка

Три ратифицированных входа, каждый — отдельным вагоном ДО прогона:

1. **Политика v1.1** ([labeling-policy-b2](../specs/labeling-policy-b2.md)
   аддендум 1): whitelist изменяемых полей конверта (дата наблюдения —
   не контент), пунктуация заголовка = косметика (T1), razor-зона
   (0.95; 1.0) двузначна — T1-косметика там позитив, T3-факт-правка там
   негатив.
2. **Sanity v2** ([eval-methodology](../specs/eval-methodology.md) §10,
   секция `sanity_v2` контракта ревизии v3): двусторонний policy-aware
   экзамен — cosmetic_twin ≥ 0.5, fact_edit_twin < 0.5,
   envelope_variant ≥ 0.5, зонная монотонность (ступени 1.0 → 0.99 → 0.95
   не проверяются).
3. **C1-диагноз остановленной сессии**
   ([b2p-v41-sanity-fail-diagnosis](b2p-v41-sanity-fail-diagnosis.md),
   волна D4-4, PR #13): диагноз красного сьюта B2-v41 — probe-in-overlap
   (сьютовская T3-проба same-length сидит в T1-облаке) + вне-зонное
   плато монотонности (нет класса «высокий char-оверлап ∧ низкий
   косинус = NOT-dup»). Авторство честно: диагноз исполнен сессией
   B2-prime-волны, остановленной после диагностики; владелец направил
   «учти наработки остановленной сессии», TL ратифицировал диагноз и
   вариант C1 (корпусная коррекция, без ослабления сьюта — анти-HARKing).
