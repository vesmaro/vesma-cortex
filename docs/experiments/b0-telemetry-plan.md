# B0: план прод-наблюдения (телеметрия 2-часового цикла)

- **Статус:** активен (таймер `vesma-cortex-metrics.timer`, каждые 2 ч)
- **Окно:** 14 дней, 2026-10-03 → 2026-10-16; промежуточная точка — день 7
  (2026-10-09)
- **Модель в проде:** на старте окна — vesma-cortex-v1 rev B2
  (`71f0572d…`), флаг `mnemos.decision_provider: vesma` (прод-конфиг);
  с 23:07 UTC 2026-10-03 — **B1 `beb0a65d`** (отзыв B2 — см. Аддендум 1 ниже
  и [протокол отзыва](b0-escalation.md))

## Что собирается (каждые 2 ч, хост-коллектор)

`cortex-metrics.sh` → `telemetry/metrics-2h.jsonl` (одна JSON-строка):
service_state, health, счётчики CORTEX-E-{LOAD,META,PIN,SCHEMA,INFER,SIZE}
за окно 2 ч, decision-строки из журнала (provider/confidence/is-duplicate),
CPU% и RSS процесса сервера.

## Критерии успешности окна (ВСЕ одновременно, к дню 14)

1. **Стабильность:** service active ≥ 99 % сэмплов; 0 crash-loop'ов.
2. **Здоровье провайдера:** 0 × `CORTEX-E-PIN`; суммарно ≤ 2 прочих
   CORTEX-E (каждый с документированной транзиентной причиной).
3. **Сигнал ценности:** доля решений, где вердикт модели отличается от
   косинус-базлайна (delta-rate) — в коридоре ≥ 5 % (ниже — модель не
   добавляет ничего сверх эвристики).
4. **Без вреда:** 0 подтверждённых владельцем вредных подсказок
   (роль advisory — ложное срабатывание раздражает, но не разрушает).
5. **Полнота телеметрии:** ≥ 90 % сэмплов 2-часового цикла присутствуют
   (ожидание ~168 строк).

## Критерии провала (ЛЮБОЙ → откат флага + разбор)

1. Crash-loop или повторяющиеся неудачные старты → немедленный откат
   `decision_provider` → deterministic + расследование.
2. Устойчивый `CORTEX-E-PIN` (дрифт эмбеддера) → полный цикл
   перекалибровки.
3. Подтверждённый владельцем вред от подсказок → немедленный откат.
4. Полнота телеметрии < 60 % → окно неинтерпретируемо: продлить или
   пере-инструментовать.

## Откат (одна строка)

`mnemos.decision_provider: deterministic` в прод-конфиге + рестарт
`mnemos-prod-laptop` (runbook: docs/runbooks/operator-protocol.md, режим
recalibrate).

## Аддендум 1 (2026-10-03, до дня 7)

> Внесён в день отзыва B2 из прода
> ([b0-escalation.md](b0-escalation.md)); меняет интерпретацию критериев,
> не сами критерии. Пороги гейтов — в [eval-methodology](../specs/eval-methodology.md)
> и `gate_contract.json` (ADR 0003).

### (а) cos-полосный no-harm-коридор

При cos ≥ 0.95 косинус-базлайн — почти оракул: выше полосы оба сходятся,
модель не добавляет ничего, но и ломать нечему. Расход модели с базлайном
в полосе (> 10 % решений внутри cos ≥ 0.95) — **полевой симптом класса
#480** (инверсия/сдвиг на тривиально-безопасной поверхности). Грейд —
коридор, не провал: сигнал на разбор, решения не откатываются автоматически.

### (б) Знаковый критерий дельты

Критерий 3 (delta-rate ≥ 5 %) валиден только с **разметкой знака**:
расхождение с базлайном само по себе не ценность — надо знать, кто прав.
По выборке расхождений дня 7 считается доля случаев, где прав базлайн
(разметка — владелец). Если прав базлайн в большинстве — модель не
добавляет ценности, критерий 3 не засчитывается, даже при формальном
delta-rate ≥ 5 %.
