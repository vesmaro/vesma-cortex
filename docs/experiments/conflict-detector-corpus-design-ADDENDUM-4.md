# ADDENDUM-4 к дизайн-пакету conflict-detector — вопрос MLC: нога-2 пробы 7 (cross-изменённый-факт) на frozen-13 — вердикт о поверхности

- **Статус:** DRAFT (позиция TL 10.11) → узкий MLC-раунд (позиции → синтез → ратификация).
- **Триггер:** instrument-abort на sanity §6.3 проба 7-нога-2 при перегоне v2
  (09.11; фикс-факты в run-log slice conflict-detector-v2-*). Проба 6 — GREEN
  (цель amend-3 достигнута); RED — новая нога той же сьюты. Holdout v1/v2
  девственны (0 чтений за всю историю), гейт закрыт до зелёной сьюты.

## 1. Факты (механически верифицированы, скрипт `b6_conflict_cross_cell_analysis.py` @ 45737d2)

| Факт | Число |
|---|---|

| До ближайшего train-ряда любого класса | L2 ≥ 4.243 (в 4–8 раз дальше) |
| Единственная живая координата cross-ячейки | `cos_target` (char3/4/5 ≈ 0 на разных алфавитах; tag/type/lang — константы) |
| Δcos между ногами | **0.001** — не привязано к метке (позиция cos = функция формулировки, не факта) |
| Cross-позитивы v2 (15 пар) | cos [0.7002, 0.7458] — саппорт заканчивается на 0.7458 |

**Объяснение флипа v1→v2:** в v1 cross-негативы были только тривиальные
(NC-4-lang, cos=1.0) ⇒ всё реальный cross звонился contradicts — нога-2 была
зелёной В СИЛУ ПУСТОГО негативного саппорта (и нога-1/диагностик при этом
красные: v1 звала истинный перевод contradicts p≈1). v2 добавила реальные
cross-негативы (N3) ⇒ граница съехала на заселённую полосу ⇒ нога-1 и
диагностик зелёные, нога-2 красная. Обе модели неверны ровно на одной
стороне; требуемая сьютой дискриминация ног — одна точка поверхности.

## 2. Почему «заселить полосу позитивами» НЕ чинит (разбор фикс-предложения аналитика)

Заселение [0.75,0.80) cross-позитивами: (а) не даёт координаты, различающей
ноги — обе на cos≈0.774, Δ=0.001; (б) любая выученная граница в этой полосе
разворачивает одну из ног в RED (позиции ног взаимно перекрываются и
перемешиваются пере-формулировкой); (в) создаёт противоречивые метки в одной
фич-клетке с N3 (семантическая метка на мёртвых координатах) = обучение
шуму. Класс аргумента P0 E4 («для фич это одна и та же точка») — теперь
подтверждён измерением L2, не аналогией.

## 3. Позиция TL (на ратификацию)

**Нога-2 пробы 7 физически неудовлетворима на frozen-13** — вердикт о
поверхности (класс OQ-3/фиче-контракт), НЕ curriculum-gap, НЕ подгонка
фикстуры под крас. Механическое доказательство — §1. Предлагаемое
постановление:

1. **Suite-амендмент (pre-registered, ратифицируется этим аддендумом):**
   проба 7 исполняется на frozen-13 как ОДНОНОЖЕВАЯ (leg-1: истинный
   перевод → NOT; сейчас GREEN). Нога-2 переводится в known-uncovered
   (декларация в MODEL_CARD + ADOPT-отчёт), откладывается в фазу
   OQ-3 (content-derived cross-фичи — та же фаза, что e_cos/zeps-класс
   для razor).
2. **Прецедентная оговорка (расширение E13):** объявление ноги
   known-uncovered допустимо только при (i) механическом доказательстве
   «одной точки» на конкретной поверхности (L2-свидетельство §1);
   (ii) неизменённости остальных ног и гейтов; (iii) публикации
   ограничения в каждой цитате чисел прибора («известная слепая зона,
   не тишина»); (iv) обратимости: при росте фичевой поверхности (OQ-3)
   нога возвращается в сьюту ДО любых новых гейтов.
3. **Диагностик истинного перевода** (0.7748, вне словаря корпуса) —
   остаётся публикуемым числом честности; на v2 он ЗЕЛЁНЫЙ — фиксировать
   как достигнутый фикс (v1 ломала).
4. Дальнейший путь линии: перегон v2 с амендированной сьютой → TL-гейт →
   Ф2 single-shot на CD-holdout-v2 → вердикт §6.2. Если MLC вместо этого
   выберет «линия стоит до OQ-3» — честный STOP с полным сохранением
   девственности печатей (все артефакты v2 готовы к гейту).
