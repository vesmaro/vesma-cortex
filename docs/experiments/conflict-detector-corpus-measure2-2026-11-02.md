## Диагноз (закрывает вопрос брифа «какая из версий (а)–(в)»)

Подтвердилась **версия (а)**: конструкции систематически уходят ВЫШЕ
0.70. Незакоммиченный фикс предыдущего исполнителя (CD-6x
translation-negation + SPEC-короткие тела) работу продолжил и частично
углубил пул, но окно не достиг: его SPEC-префикс (общая строка в обеих
сторонах) наоборот поднимает cos (CD-5 легла 0.95+), а причину он
устранить не успел.

**Корневая причина — рассинхрон измерительных поверхностей.** Пробы
measure (еvidence ADDENDUM-1: 0.6851–0.6985 в окне) мерились на СЫРОМ
тексте без конверта; корпус считается по ратифицированной конвенции
§4.3 (title+body+tags). Конверт (переводные тайтлы одного субъекта +
общий тег) поднимает same-subject пары на +0.08…+0.12 (замер по сетке
поверхностей, 78 проб). На конвенции прибора:

- same-lang (RU-RU) позитивы: **min 0.9449** по всему пулу;
- кросс-языковые позитивы: **min 0.6636** (CD-2), CD-6 min 0.6756;
- окно [0.60,0.70) по ВСЕМ позитивам пула: **17**, по ратифицированным
  источникам CD-5/CD-6/CD-1-парафраз: **6** при поле **≥ 30**.

Свойство прибора «same-subject ≥ ~0.68 raw» (ADDENDUM-1 §A) + конверт
делают окно недостижимым для ЛЮБОЙ конструкции конфликта: противоречие
требует общего предиката-топика, а это и есть нижняя граница прибора.

## Варианты председателю (НЕ применены — только числа)

1. **Пере-эджить трудное окно в [0.70, 0.75): ≥ 30 позитивов** (рекомендация).
   Факт пула: 194 позитивов (все кросс-языковые CD-1/CD-2/CD-6x) + 114
   негативов NC-5 в том же диапазоне — смешанный анти-шорткат бан
   (главная защита от прокси «по косинусу») сохраняется, носитель просто
   сдвигается туда, где он физически есть на приборе. [0.70,0.80) даёт
   463/146 с ещё большим запасом. Число ≥ 30 и смешанность сохраняются —
   меняется только край, та же мера-калибровка, что ADDENDUM-1.
2. **Держать [0.60,0.70)** — сборка невозможна (6/30 на ратифицированных
   источниках после исчерпания обогащения); линия №6 стоит.
3. (Опционально к любому варианту) зафиксировать в манифесте
   known-uncovered `cos < 0.527` (конвенция-меренный floor корпуса) и
   тонкость b40-носителя (10/72 плана).
