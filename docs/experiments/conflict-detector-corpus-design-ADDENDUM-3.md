- **Статус:** DRAFT (позиция TL 09.11) → на MLC (позиции членов → синтез → фикс-коммит → ратификация).
- **Триггер:** sanity §6.3 проба 6 RED = instrument-abort (запись
  `post_abort_diagnosis_probe6` в run-log 09.11; holdout НЕ читан,
  `sealed_surfaces_read: 0`, печать CD-holdout-v1 цела и девственна).
  Фаза 1 верифицирована TL лично (перегон sanity бит-в-бит, bundle
  integrity, run-log дисциплина П1–П9).
- **Диагноз (верифицирован):** решающая поверхность НЕмонотонна по числу
  бенигных замен в razor-зоне: конфликт-пара CD-2 + одна бенигная
  подстановка (вторая non-equal область) → вердикт переворачивается
  (p 0.9998→0.238, char5 0.9664→0.9123), две подстановки → возвращается
  (p 0.99997). Корень: **в train razor-банде нет носителя «конфликт +
  бенигная парафраз-дельта»** — razor-позитивы все 1-областные, диалект
  para_b живёт только у cross CD-1 ниже по cos. Дополнительно
  диагностикой (не гейт): **истинный верный перевод** (cross-пара с
  РАВНЫМИ значениями слотов — вне словаря корпуса §4.4) получает
  contradicts p=0.999967.

## 3. Механические предикаты A-silver (расширение карты §3.2.1)

- **N1:** декларированные бенигные области (i) существуют, (ii) не содержат
  НИ ОДНОГО декларированного факт-токена (механический ассерт на каждой
  паре), (iii) суммарно областей = слоты + бенигные, (iv) все слотовые
  области проходят слот-биекцию как раньше.
- **N2:** как N1 + выполняемость уточнения (v ⊨ c) как в NC-2.
- **N3:** декларационная проверка «все значения слотов попарно равны» +
  языки различны; 0 non-equal слотовых областей.

## 6. Порядок после ратификации

DE: правка генератора + preflight П3 на фикстурных ячейках N1–N3 →
генерация → полная карта ассертов §5.3 (с расширениями §3) → measure→fix
бандов → манифест → seal v2 → дельта-золото (OQ-1). ML: перегон
train+floors+sanity (кода не меняя) → TL-гейт (личная верификация) →
Ф2 single-shot на v2. Каскад волны (аудиторы, волновой дифф) — после
вердикта гейтов, одним куском (теперь в дифф войдёт и аддендум-3).
