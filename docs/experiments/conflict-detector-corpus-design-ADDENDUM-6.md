# ADDENDUM-6 — исчерпание шаблонных вселенных NC-1/NC-5 (BuildStop seal3), выбор пути ротации

- **Статус:** DRAFT (позиция TL 10.11) → узкий MLC-раунд.
- **Триггер:** BuildStop полосы seal3 (581883c + ea4e2b1): ратифицированная
  таблица долей (NC-1 20 / NC-5 25 / NC-4 11) неисполнима при F6+F10 для
  ЛЮБОГО свежего сида — clean supply по text-sha: NC-1 = 1, NC-5 = 13,
  NC-4 = 12 (2x-ценз провален), NC-3 = 31 (жёстко ok, 2x нет). Доказано
  числами на 3 сидах; шоппинг сидами и ослабление F10 закрыты. Причина
  структурная: шаблонная сетка NC-классов конечна и сид-независима,
  три поколения потребления (train-v2 + v1-seal + v2-seal) исчерпали
  вселенные. Ничего не эмитировано; печати v1/v2 целы; сид 6117
  re-affirmed; seal3-код готов (581883c).

## 1. Опции (лан) — разбор TL

| Опция | Суть | Вердикт TL |
|---|---|---|
| A | перебаланс долей v3 под глубину (NC-1 → 0-1, NC-5 → ≤8, NC-4 → ≤10, NC-3 → ≤15, масса в CD-*/NC-2/N3; амендмент состава) | ОТКЛОНЕНА: нож-страта NC-1 ≥0.85 (ратифицированный гейт) становится неизмеримой (n=1) = четвёртая амендация гейт-рамки; агрегат NC дрейфует к NC-2; стена повторяется при каждой следующей ротации; eval «не-contradicts» стороны теряет addition-класс — опасно именно по false-positive оси детектора |
| B | **расширить шаблонные вселенные** исчерпанных классов (gen_pool_v3 — eval-only форк; новые банки шаблонов NC-1/NC-4/NC-5, опционально NC-3-маржа) | **ПРИНЯТЬ** (с ограничениями §2): таблица долей и гейты ЦЕЛЫ, F10 цел, структурный фикс — будущие ротации не упираются в стену |
| C | ослабить F10 | опровергнуто числами лана (1/13 на трёх сидах) |

## 2. Ограничения B (постановление в случае ратификации)

1. **gen_pool_v3 — eval-only форк:** train-путь (measure2/build2/сид 2113)
   не трогается байт-в-байт (проверка дайджестов как в seal3); новые банки
   ТОЛЬКО для исчерпанных классов (NC-1, NC-4, NC-5; NC-3 — маржа по цензу).
2. **Те же механические предикаты и анти-прокси батарея** (§3.2.1 + §4.4:
   слот-биекция, разнос ≥100, length-каналы, null-конверт, A-indep) на
   новых шаблонах ДО резки — префлайт на фикстурных ячейках, как П3.
3. **Банки шаблонов коммитятся + sha в pin-v3.json** (прецедент словаря
   PARA из E2); антиколлапс §4.5 действует на новых банках (≥20
   скаффолдов/класс, ≤5%/скаффолд).
4. **Disclosure:** holdout v3 несёт unseen-scaffold ряды расширенных
   классов — строка в seal payload lineage + MODEL_CARD known-limitations;
   риск стайл-прокси «новый стиль ⇒ NOT» для contradicts-детектора
   консервативен по false-positive оси, но публикация обязательна.
5. **Ценз E9-mini после расширения** (suitable ≥2× квоты) — до резки;
   сид 6117 re-affirmed.
6. Проверка стайл-нейтральности: новые шаблоны NC-классов прогоняются
   через тот же набор метрик длины/каналов, что старые (A-len-indep в
   разрезе старый/новый банк — ассерт |p−1/3| ≤ 0.05 внутри каждого).

## 3. Вопросы MLC

1. B против A: подтвердить B? Рекомендация: ДА (§1).
2. Ограничения §2 — принять/дополнить? Рекомендация: принять; особое
   внимание к п.4 ( disclosure unseen-scaffold) и п.6 (стайл-нейтральность).
3. NC-3-маржа: расширять или жить на clean 31 (2x-ценз для доли 15 =
   30 ≤ 31 — проходит впритык)? Рекомендация: НЕ расширять (минимальная
   хирургия; впритык фиксируется disclosure).
4. Канонизация: «конечность шаблонных вселенных = структурная стена
   ротаций; расширение вселенных — eval-only форк с теми же
   предикатами» — в ту же ML-STD-0003/корпусную канонизацию? Рекомендация: ДА.
