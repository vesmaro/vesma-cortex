## Ждут владельца

   `mnema-dedup` вместо исторического «mnema-роутер» (функциональное имя =
   защёлка от расширения задач; телеметрия без ложного следа; сейчас
   переименование бесплатно, после калибровки — audit-цена). Проза canon не
   правится — разводится терминологической строкой ADR 0001.
2. **GitHub-размещение vesmaro-cortex** — приватная репа в орге vesmaro или
   только локально. Рекомендация: приватная репа в орге (единое место контрактов
   экосистемы; canon и движок уже там).
3. **XPU walkthrough** (A4) — по ранбуку после A3; по вердикту A1 это
   провенанс-прогон + детерминизм-гейт, не техническая необходимость.
